An API rate limit is a restriction that controls how many requests a user or application can send to an API within a specific time frame, such as per minute or per day. Service providers implement these limits to prevent abuse, protect server performance, and ensure fair access for all users. When the limit is exceeded, the API stops accepting new requests until the time window resets, typically returning an error notification to indicate the threshold has been reached. Developers manage this by tracking their request counts, adding delays between calls, or requesting higher limits through an upgraded plan.
