An API rate limit is a restriction set by a service provider on how many requests a user, application, or IP address can make to an API within a specific timeframe. For example, a service might set a limit of 100 requests per minute.

Providers use rate limits to prevent server overloads, protect against malicious attacks or accidental code loops, and ensure fair performance for all users. If you exceed the allowed number of requests, the API will temporarily reject incoming traffic, typically returning an HTTP 429 Too Many Requests error, until the time limit resets.
