A database index is a specialized structure that speeds up how quickly a database can locate specific rows in a table. Without an index, the database must examine every single row to satisfy a query. An index avoids this by maintaining a separate, highly organized map of one or more columns, linking each stored value directly to its physical location in the table. When you run a search, the database consults this map to jump straight to the matching records instead of reading the entire table. This design always involves a trade-off: indexes require extra storage space and make inserting or updating data slightly slower, but they dramatically reduce the time required for read operations.
