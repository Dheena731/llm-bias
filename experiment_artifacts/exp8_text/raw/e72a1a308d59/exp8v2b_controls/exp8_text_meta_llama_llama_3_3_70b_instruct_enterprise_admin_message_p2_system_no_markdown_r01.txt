To all staff, 

We are introducing a new expense approval workflow that will be used for all employee expenses going forward. The new system is designed to streamline the approval process and provide greater transparency and accountability. 

Key features of the new workflow include automated approval routing, digital receipt storage, and real-time expense tracking. All employees are required to use the new system for expense submissions, and managers will receive notifications when approvals are pending.

Training sessions will be scheduled to ensure a smooth transition, and detailed instructions on using the new system will be provided. If you have any questions or concerns, please do not hesitate to reach out to the finance department.

Thank you for your cooperation and understanding as we implement this new process.
