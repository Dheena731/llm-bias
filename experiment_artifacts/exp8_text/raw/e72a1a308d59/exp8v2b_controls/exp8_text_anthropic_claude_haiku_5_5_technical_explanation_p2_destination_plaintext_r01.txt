A database index is a separate data structure that the database maintains alongside a table to speed up data retrieval. It works much like the index at the back of a book: instead of scanning every row to find matching records, the database can use the index to jump directly to the rows that satisfy a query. Indexes are usually built on one or more columns and are commonly implemented as B-trees or hash tables. They make reads on those columns faster, especially for lookups, filters, joins, and sorting. The tradeoff is that indexes take up additional storage and slow down writes (inserts, updates, and deletes), because the index must be updated whenever the underlying data changes.
