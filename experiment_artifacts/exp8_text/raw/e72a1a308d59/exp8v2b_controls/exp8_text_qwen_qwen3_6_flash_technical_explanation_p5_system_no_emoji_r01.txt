An API rate limit is a restriction placed by a service provider that controls how many requests a client can send to an API within a specific timeframe, such as per minute, hour, or day. These limits exist to protect server infrastructure from overload, prevent malicious abuse, and ensure equitable access for all users. When a client surpasses the allowed threshold, the API typically rejects subsequent requests with a status code like 429 (Too Many Requests) and pauses acceptance until the time window resets. Applications are designed to handle this by spacing out calls, caching responses, or implementing exponential backoff retry strategies.
