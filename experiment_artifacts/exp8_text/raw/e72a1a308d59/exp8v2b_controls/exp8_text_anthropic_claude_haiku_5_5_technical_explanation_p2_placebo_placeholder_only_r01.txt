A database index is a separate data structure that speeds up the retrieval of rows from a table. Without an index, a query that searches for specific values typically has to scan every row in the table to find matches, which becomes slow as the table grows. An index works like the index at the back of a book: it stores a sorted or organized copy of one or more columns, along with pointers to the locations of the matching rows. When a query filters or sorts on an indexed column, the database can use the index to jump directly to the relevant rows instead of reading the entire table.

Indexes improve read performance, but they are not free. Each index takes up additional storage, and every insert, update, or delete must also update the index, which adds overhead to write operations. For this reason, databases are usually indexed selectively, focusing on columns that are frequently used in search conditions, joins, or ordering.
