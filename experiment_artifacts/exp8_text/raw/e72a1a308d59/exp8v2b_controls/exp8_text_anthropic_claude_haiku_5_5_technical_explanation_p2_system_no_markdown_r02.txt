A database index is a separate data structure that the database maintains alongside a table to speed up data retrieval. Much like the index at the back of a book, it lets the database locate rows matching a condition without scanning every row in the table. Indexes are typically built on one or more columns, and they store the indexed values in an organized form, such as a B-tree, along with pointers to the corresponding rows. When a query filters, sorts, or joins on an indexed column, the database can use the index to jump directly to the relevant rows. The trade-off is that indexes consume additional storage and slow down writes, since each insert, update, or delete must also update the index.
