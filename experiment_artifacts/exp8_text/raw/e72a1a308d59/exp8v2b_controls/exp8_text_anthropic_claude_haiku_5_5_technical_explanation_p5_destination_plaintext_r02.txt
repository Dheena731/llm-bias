An API rate limit is a restriction on how many requests a client can send to an API within a set period of time. For example, a service might allow 100 requests per minute from a single user or API key. If a client exceeds that limit, the server typically rejects further requests for a while, often returning an error such as HTTP 429 "Too Many Requests." Rate limits protect servers from overload, help ensure fair access for all users, and control costs for the provider.
