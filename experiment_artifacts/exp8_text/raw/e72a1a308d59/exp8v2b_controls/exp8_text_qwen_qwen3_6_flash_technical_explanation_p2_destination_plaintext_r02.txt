A database index is a data structure that improves the speed of data retrieval operations on a database table at the cost of additional writes and storage space. Functionally, it acts like a reference map that allows the database to locate specific rows quickly without scanning the entire table. Without an index, the database must perform a full table scan, checking every row one by one, which becomes extremely slow as the dataset grows. Instead, an index organizes data values in a structured format, such as a B-tree, enabling the engine to jump directly to the relevant records. This is analogous to the index at the back of a book, which directs you to the correct pages instantly rather than requiring you to read every page. While indexes significantly accelerate read queries, they consume extra disk space and can introduce slight overhead during data modification operations like inserts, updates, and deletes, since the index must also be updated whenever the underlying data changes.
