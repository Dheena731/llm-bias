A database index is a separate data structure that the database maintains alongside a table to speed up searches. Without an index, finding rows that match a condition (for example, every customer whose last name is "Smith") usually requires a full table scan, meaning the database reads every row to check it. An index stores the values of one or more columns in a sorted or otherwise searchable form, along with pointers to the rows holding those values. The database can then jump directly to the matching entries instead of reading the whole table.

The trade-off is that indexes take up additional storage, and every insert, update, or delete must also update the relevant indexes, which adds some cost to writes. For this reason, indexes are typically created on columns that are frequently used in search conditions, joins, or sorting, rather than on every column.
