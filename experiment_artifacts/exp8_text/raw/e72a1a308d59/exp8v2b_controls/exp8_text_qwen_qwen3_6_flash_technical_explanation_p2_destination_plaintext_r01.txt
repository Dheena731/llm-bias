A database index is a data structure that speeds up data retrieval in a table. It works like the index at the back of a book or a library catalog, allowing the database engine to find specific rows without scanning every single record. When you query data using columns that are indexed, the database uses this structure to locate matching rows quickly instead of performing a full table scan. However, indexes come with trade offs: they require extra storage space and can slow down write operations like inserts and updates, since the index must be rebuilt or updated whenever the underlying data changes. In short, indexes optimize read performance at the cost of additional disk usage and slower writes.
