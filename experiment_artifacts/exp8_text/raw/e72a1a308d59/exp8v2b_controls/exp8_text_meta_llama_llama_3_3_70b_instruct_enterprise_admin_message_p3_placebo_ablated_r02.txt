Here is a short message announcing a change to the VPN client:

"Important Update: The VPN client used to access our company's network remotely will be updated on [Date]. The new version will provide improved security and stability. All users who currently use the VPN client will need to download and install the updated version to continue accessing the network. Instructions on how to update the client will be provided separately. If you have any questions or concerns, please reach out to the IT department."

I made sure to:

* Clearly state the main point (the VPN client is being updated)
* Avoid using technical jargon that may be unfamiliar to non-technical users
* Address the correct audience (users who currently use the VPN client)
* Provide a clear call to action (download and install the updated version)
* Offer support for users who may have questions or concerns (contact the IT department)
