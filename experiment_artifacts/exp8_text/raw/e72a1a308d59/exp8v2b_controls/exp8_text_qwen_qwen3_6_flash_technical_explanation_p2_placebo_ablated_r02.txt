A database index is a specialized data structure designed to speed up data retrieval. Without an index, finding specific records requires scanning every row in a table one by one—a process that becomes slow as data grows. An index resolves this by maintaining a sorted reference that maps specific column values directly to the locations of their corresponding rows. This allows the database engine to skip irrelevant data and jump straight to the results. 

Like a book’s index, this approach trades a small amount of extra storage and slightly slower write operations (inserts, updates, and deletes) for significantly faster read performance. Because maintaining an index adds overhead, they are added selectively to columns that are frequently searched, sorted, or used to link related data together.
