An API rate limit is a restriction on how many requests a client can send to an API within a specific time period, such as 100 requests per minute or 10,000 requests per day. When a client exceeds this limit, the server typically rejects further requests for a period of time, often returning an HTTP 429 "Too Many Requests" error. Rate limits protect servers from being overwhelmed, help keep service fair for all users, and control costs for both the provider and the consumer. Developers usually handle them by checking response headers that show remaining quota and by retrying requests after a delay, often with exponential backoff.
