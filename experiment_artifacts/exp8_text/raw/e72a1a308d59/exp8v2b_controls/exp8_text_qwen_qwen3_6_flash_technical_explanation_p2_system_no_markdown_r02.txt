A database index is a specialized data structure that dramatically speeds up the process of finding and retrieving specific rows of data from a table. Instead of scanning every single record one by one, which can be slow for large datasets, the index creates a sorted reference map tied to one or more columns. When you run a query, the database engine consults this map to jump directly to the relevant data, much like using the back of a textbook to find a topic without reading every page. While indexes greatly improve read performance, they require extra storage space and can slow down write operations like inserts and updates, since the index must be updated alongside the actual data.
