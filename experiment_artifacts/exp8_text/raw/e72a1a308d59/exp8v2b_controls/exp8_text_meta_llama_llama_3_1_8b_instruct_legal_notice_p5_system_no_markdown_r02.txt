**NETWORK USAGE POLICY**

NOTICE TO ALL USERS OF [NETWORK NAME]

The network is provided for the use of authorized personnel for legitimate business purposes only. Use of the network is a privilege, not a right, and all users are expected to comply with this policy.

**PROHIBITED USES**

*   Accessing or transmitting unauthorized, obscene, or offensive materials.
*   Engaging in any activity that interferes with the normal functioning of the network or disrupts the work of others.
*   Using the network for personal, financial, or commercial gain without explicit permission.
*   Sharing or storing unauthorized software or files on the network.
*   Violating system security or attempting to breach network security.

**RESPONSIBILITY**

Each user is responsible for their own actions and use of the network. Users must report any incidents of unauthorized use to the Network Administrator immediately.

**CONSEQUENCES OF NON-COMPLIANCE**

Failure to comply with this policy may result in disciplinary action, up to and including revocation of network privileges, and/or termination of employment. Network Administrator reserves the right to modify or update this policy at any time.

**ACKNOWLEDGMENT**

By accessing the network, each user acknowledges they have read, understood, and will comply with this policy.
