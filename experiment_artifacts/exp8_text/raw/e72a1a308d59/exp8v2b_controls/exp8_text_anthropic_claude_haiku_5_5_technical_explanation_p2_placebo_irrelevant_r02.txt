A database index is a data structure that speeds up the retrieval of rows from a table. Much like the index at the back of a book, which lets you jump straight to a topic instead of reading every page, a database index stores the values of one or more columns in a sorted or otherwise searchable form, along with pointers to the rows that contain them. When a query filters or sorts on an indexed column, the database can use the index to locate matching rows quickly rather than scanning the entire table. The trade-off is that indexes take up additional storage and must be updated whenever the indexed data changes, so they slow down inserts, updates, and deletes. For that reason, indexes are typically created on columns that are frequently used in searches, joins, or ordering.
