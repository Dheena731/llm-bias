A database index is a data structure that speeds up the retrieval of rows from a table. Much like the index at the back of a book, which lets you jump straight to the page covering a topic instead of reading every page, a database index lets the database locate matching records without scanning the entire table.

Indexes are typically built on one or more columns. The database maintains a sorted or hashed structure, often a B-tree, that maps column values to the physical locations of their rows. When a query filters or sorts on an indexed column, the database can consult this structure to find matches quickly.

The trade-off is that indexes consume additional storage and slow down writes, since every insert, update, or delete must also update the index. For this reason, indexes are usually added to columns that are frequently used in search conditions, joins, or ordering, rather than to every column.
