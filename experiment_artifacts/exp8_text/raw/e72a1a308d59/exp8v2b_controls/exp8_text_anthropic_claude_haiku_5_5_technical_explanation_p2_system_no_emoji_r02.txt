A database index is a separate data structure that helps the database find rows quickly without scanning an entire table. It works much like the index at the back of a book: instead of reading every page to find a topic, you look it up in the index and go directly to the right page.

Typically, an index stores the values of one or more columns in a sorted or hashed form, along with pointers to the rows that contain those values. When a query filters or sorts on an indexed column, the database can use the index to locate matching rows efficiently, often reducing lookup time from linear to logarithmic.

The tradeoff is that indexes take up additional storage and must be updated whenever the indexed data changes, which slows down inserts, updates, and deletes. Good indexing balances faster reads against the cost of writes and storage.
