A database index is a data structure that improves the speed of data retrieval operations on a table, functioning much like an index at the back of a book. 

Without an index, the database must perform a "full table scan," checking every single row to find the requested information. With an index, the database can directly look up the location of the data, significantly reducing query response times.

While indexes make searching and reading data much faster, they require additional storage space and can slightly slow down write operations (such as inserting, updating, or deleting rows), because the index must be updated every time the data changes.
