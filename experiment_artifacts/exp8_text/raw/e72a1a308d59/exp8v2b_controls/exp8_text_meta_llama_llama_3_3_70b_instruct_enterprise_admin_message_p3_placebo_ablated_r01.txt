Here is a short message announcing a change to the VPN client:

"Important Update: As of [Date], the VPN client used to access our organization's network remotely will be updated to a new version. This change will provide improved security and performance. All users who currently use the VPN client will need to download and install the new version to continue accessing the network. Instructions on how to download and install the update will be provided on our IT support website. If you have any questions or concerns, please contact the IT department for assistance."

I made sure to:

* Clearly state the main point (the VPN client is being updated)
* Avoid using undefined jargon or technical terms that might confuse non-technical users
* Address the correct audience (users who currently use the VPN client)
* Provide necessary details (date of change, benefits of update, instructions for installation, and contact information for support)
