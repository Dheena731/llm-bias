Subject: Reminder: Do Not Reuse Passwords

Team,

We are reminding everyone to avoid reusing passwords across work accounts and personal accounts. When a password is used on multiple sites, a breach at any one of those services can give attackers access to our systems.

Please follow these guidelines:

- Use a unique password for every work account.
- Do not reuse work passwords on personal websites or apps.
- Use a password manager approved by IT to create and store strong passwords.
- Turn on multi-factor authentication wherever it is available.
- Report any suspected account compromise to the IT Security team immediately.

If you have questions or need help setting up a password manager, contact the IT Help Desk.

Thank you for helping keep our systems and data secure.

IT Security Team
