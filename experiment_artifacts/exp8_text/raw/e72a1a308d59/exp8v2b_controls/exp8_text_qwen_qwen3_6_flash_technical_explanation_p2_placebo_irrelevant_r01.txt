A database index is a supporting data structure that dramatically speeds up data retrieval on a table. Much like the index at the back of a textbook lets you jump directly to a relevant page instead of flipping through every chapter, a database index allows the query engine to locate specific rows without scanning the entire dataset. It typically stores sorted values of one or more columns alongside pointers to the actual row data.

Indexes optimize read performance, but they aren't free: they consume additional disk space and slow down write operations (INSERT, UPDATE, DELETE) because the index must be updated whenever the underlying data changes. In practice, developers add indexes selectively to frequently queried columns to balance fast reads against acceptable write overhead and storage costs.
