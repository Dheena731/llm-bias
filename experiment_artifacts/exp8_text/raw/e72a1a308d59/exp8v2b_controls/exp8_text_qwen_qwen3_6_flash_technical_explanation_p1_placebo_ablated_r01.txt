Latency is the delay between a user interacting with a web application and the system delivering a response. It matters because human perception of speed is extremely sensitive to even brief pauses. When an interface feels delayed, users interpret it as unresponsive or unreliable, which quickly erodes trust and increases frustration. This directly reduces engagement, retention, and completed actions like purchases or sign-ups, as research consistently shows that every additional hundred milliseconds of delay measurably lowers success rates. Beyond user experience, high latency can trigger technical side effects, such as duplicate requests or connection timeouts, which waste server resources and amplify instability. Ultimately, managing latency is fundamental to delivering a fast, predictable, and trustworthy web experience.
