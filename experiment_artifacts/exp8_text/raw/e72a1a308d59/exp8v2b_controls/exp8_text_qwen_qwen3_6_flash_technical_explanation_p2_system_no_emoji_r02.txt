A database index is a specialized data structure that accelerates data retrieval by acting as a quick-reference map to specific rows in a table. Instead of scanning every record when executing a query, the database consults the index to locate matching data almost instantly, much like using a book's index to find a topic rather than reading every page. While indexes dramatically improve the speed of read operations such as searches, filters, and joins, they consume additional storage space and slightly slow down write operations, since the index must be rebuilt or updated whenever data is inserted, modified, or deleted.
