**Caching** speeds up a website by saving copies of files and data in temporary storage so the system doesn’t have to rebuild or re-download them every time a page is loaded. 

Think of it like keeping a frequently used document on your desk instead of walking to the file room every time you need to read it.

Here is how it works and why it makes sites faster:

### 1. It skips repetitive processing (Server-side caching)
Without caching, every time you visit a webpage, the web server has to run code, query a database for content, and assemble the page’s HTML from scratch. With caching, the server creates that page once, saves a "snapshot" of the finished product, and serves that pre-built snapshot instantly to the next visitor.

### 2. It cuts down physical travel distance (CDN caching)
Content Delivery Networks (CDNs) store copies of a website’s static content (like images, videos, and styling files) on servers distributed around the world. Instead of your request traveling thousands of miles to an origin server, a CDN cache serves the files from a local server physically close to you, drastically reducing lag (latency).

### 3. It prevents redundant downloads (Browser caching)
Your web browser saves elements like logos, fonts, and style sheets locally on your device. When you navigate to a new page on the same site, your browser doesn't download those shared assets again—it simply loads them from your computer’s hard drive, which happens almost instantaneously.

---

**In summary:** Caching speeds up websites by **reducing server workload**, **cutting down network travel time**, and **eliminating redundant downloads**, turning a multi-step process into near-instant delivery.
