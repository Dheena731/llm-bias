A database index is a specialized data structure that speeds up how quickly a database can find rows of data without scanning every single record. It works by creating a sorted reference list pointing to the actual stored data, much like the index at the back of a book helps you locate specific topics instantly. When you run a query filtering results on an indexed column, the database uses this structure to jump directly to the matching rows instead of reading the entire table. This makes read operations significantly faster, though it does require additional storage space and can slightly slow down write operations like inserts or updates, since the index must be kept up to date whenever the underlying data changes.
