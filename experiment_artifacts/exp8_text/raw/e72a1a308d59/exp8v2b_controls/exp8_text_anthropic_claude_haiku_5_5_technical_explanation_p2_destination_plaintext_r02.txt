A database index is a separate data structure that the database maintains alongside a table to speed up lookups. Instead of scanning every row to find matching records, the database can use the index to jump directly to the rows that satisfy a query's conditions, much like using the index at the back of a book to find a topic without reading every page. Indexes are typically built on one or more columns and are commonly implemented as B-trees or hash tables. They make reads such as searches, filters, joins, and sorts much faster, but they add some overhead: they take up extra storage, and they must be updated whenever rows are inserted, updated, or deleted, which can slow down write operations.
