TASK 6 - Word count

Compute the word count of the text you entered in task 2.

You can use pyperclip or subprocess to do this. The pyperclip library is convenient, because you can pipe the text from task 2 directly to the pyperclip program with a simple call to pyperclip.copy().

Here is an example of how to use pyperclip:

from pyperclip import clip

text = input('Text to be copied: ')
print('The text is:', clip(), 'with', len(clip()), 'words')

A simple way to use subprocess is as follows:

from subprocess import call

text = input('Text to be copied: ')
call(['wc', '-w', text]).stdout

If this is your first time using either of the above, you might have to install pyperclip with pip.

pip install pyperclip

Or you might have to install subprocess with pip.

pip install subprocess
