What to write

You could begin by apologizing for the GHETTO outage. Then, explain what happened and how you fixed it. Make your tweet conversational.

what to write after a code outage

The tweet can begin with a brief phrase about what happened. Then, you can expand on it with a few explaining words. A good ending is an apology.

I can't believe it! We're sorry for the GHETTO outage, and just to make sure it doesn't happen again, we've made a few changes.

What not to write

  • This post is for customers only.
  • Sorry for the inconvenience caused, we're working on it.
  • Sorry for the interruption, we're working on it.

The examples above are generic and lack empathy. They don't offer meaningful information, and they don't sound like a person talking to another person.

The best solutions to outages

For that reason, you should avoid using the third-person where possible, and instead use the first-person.

What else to consider

Is the message delivered?

  • Is the message conversational?
  • Does it sound like a person wrote it?
  • Does it offer meaningful information?

The best message to send

The best message is short, conversational, and offers meaningful information.

You could say something like this:

Sorry for the unexpected downtime. We've fixed the issue, and we're working to make sure it never happens again.
