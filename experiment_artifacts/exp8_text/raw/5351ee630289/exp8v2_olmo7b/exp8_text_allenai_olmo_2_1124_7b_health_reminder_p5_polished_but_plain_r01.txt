Create the article

Create an article in Markdown with the following structure:

  1. Title: Write an article title that describes the topic.
  2. Introduction: Write an introduction that explains the context and introduces the topic. Introduce immediately any terms that are crucial to the topic.
  3. Body: Write the main content.
  4. Conclusion: Write a summary section that summarizes the article and describes recommended actions. Also, add any links to related articles.

Create a web page

Create a web page for the article with the following structure:

  1. Headline: Write a headline that describes the topic.
  2. Introductory text: Write a short text that describes the article.
  3. Article: Write the article in plain text.
  4. Related articles: Write a list of related articles with links to those articles.

Keep in mind

Articles are supposed to be readable before they are published. Proofread the articles again and again.

Readers will likely be attracted to articles with easy-to-read and interesting titles. So, make sure that you invest some time in the title and the introductory paragraph.

Assume that readers will be using the site to help them solve a problem or answer a question. Write articles for the reader, not for yourself. Write what the reader needs to know, not what you want to write.
