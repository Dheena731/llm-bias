What to do next

Congrats on getting this far! Before moving on to the next exercise, let’s get some details about expenses right.

Expense ID

In our current setup, there is no unique identifier for expenses. However, each expense can have a unique identifier that is not exposed to users. To set this up, do the following:

  1. In the expense spreadsheet, add a new column called Expense ID.

  2. Add the id: expense_id:{{}} field to the Expense Details page.

  3. Add an id: expense_id:{{task.valueProperty('id')}} to the Expense Approval page.

Now, whenever a new expense is created, a new expense id is created (in the expense spreadsheet column). This id is displayed in the Expense Details page. Whenever an expense is approved, the corresponding expense id is deleted from the Expense Approval page.

Expense Categories

In our current setup, all expenses are placed into a single category. However, you may want to have multiple categories such as Expense, Development, Office Supplies, etc. To set this up, do the following:

  1. Go to the expense spreadsheet, add a new column called Category.

  2. Add the expense_category:{{}} field to the Expense Details page.

  3. Add an expense_category:{{task.valueProperty('expense_category')}} field to the Expense Approval page.

Now, when an expense is created, it is assigned a category (in the expense spreadsheet column). The expense category is displayed in the Expense Details page. Whenever an expense is approved, the corresponding category is deleted from the Expense Approval page.
