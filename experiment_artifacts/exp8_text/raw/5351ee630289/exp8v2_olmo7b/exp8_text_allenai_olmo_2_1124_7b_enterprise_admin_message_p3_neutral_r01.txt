Now on to encryption. I want to encrypt the messages so that even though we've got a secure connection, the messages themselves are still safe. There are a few ways to do this, but the one that I'm going to use here is to use a key to encrypt the message.

If we just used the pre-shared key to encrypt the message, then we'd be in trouble if someone intercepted the message while it was in transit. They'd just work out what the pre-shared key was, and they'd be able to decrypt it.

So what we're going to do is a two step process. The first part is to create a symmetric key that only we know, and use that to encrypt the message. Then we'll encrypt the symmetric key with the pre-shared key.

Why do we want to do this? Well, if someone intercepts the message, they can't decrypt it without knowing our symmetric key. If they knew our symmetric key, then they'd be able to decrypt it, but because they only have the encrypted symmetric key, they can't decrypt that.

To do this, we need to use an encryption algorithm that is available in both the .NET framework and OpenSSL. We're going to use AES to encrypt the message, and RSA to encrypt the symmetric key.
