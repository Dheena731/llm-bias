An index is a structure or database object that improves the speed of data retrieval operations on a database table at the cost of additional writes and storage space to maintain the index data structure. Every row in a database table usually has an associated index; an index contains one or more keys that are used to order and retrieve data. The purpose of a database index is to find and retrieve rows with specific column values quickly.
