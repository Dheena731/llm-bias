To provide students with an opportunity to create a work plan for an app marketing launch, such as the cover letter and launch note mentioned above, ask students to develop a work plan for an app marketing launch project.

As a class, identify project goals and key tasks. This should be a short list, and students should be able to explain the goals and key tasks associated with the project. Students might include tasks such as:

  • Study sample app descriptions and make notes on key features.
  • List features in the app launch description.
  • Create the launch note.
  • Make a list of target markets.
  • Write about the target market in the launch note.
  • List value to the target market.
  • Write about the value in the launch note.

Students will also want to identify a due date for the assignment, which will be listed on the work plan, along with tasks that will be completed earlier than the due date. For example, if the description of the app is due on 5/31, students could add the task of completing the work plan to the group work plan.
