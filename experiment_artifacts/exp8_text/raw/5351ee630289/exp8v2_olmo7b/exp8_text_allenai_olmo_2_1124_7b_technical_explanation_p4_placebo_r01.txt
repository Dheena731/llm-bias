Seeing as this is timed, I will keep this short and sweet:

A Cache is a temporary storage area for frequently accessed data. Servers serve up web pages based on the request of a client’s browser (the user). Because an individual page can be requested by multiple browsers, the server stores a copy of that page in a cache file to be used later.

Over time, as the server receives more requests for a page, that page will be moved from memory to the cache. As the cache fills up, the least recently accessed items are deleted from the cache.

The server only serves pages from the cache layer if they’re in there already, otherwise it has to go back to the data store and re-fetch the content. This adds latency.

Using a cache layer, the server can distribute the page fetching work across its multiple CPU cores to reduce latency. The net result is a faster server, which I assume translates to ‘faster server = faster website’.
