Guided Project

A guided project is a project that teaches a tool, platform, or workflow.

A guided project can teach users how to find, use, and create a project or inform them about a feature or workflow.

A guided project teaches new users how to use a tool or platform by walking them through completing one or more actions.

A guided project is usually a project type that users can create.

In the Guides section, users can create both the project type and the project itself.

The first section of a guided project is always the Intro page.

The Intro page gives users the opportunity to learn about the project type and the platform.

A guided project may have additional pages after the Intro page. A guided project type may have a Requirements page, which outlines the project requirements or prerequisites.

The Requirements page is optional. It's typically used to outline project requirements or prerequisites before users begin working on the project.
