"Confidence Interval: This chart displays a range of values, called a confidence interval, which represents the potential actual value of this metric, given a certain level of confidence. It helps gauge the reliability of the data. The higher the confidence level, the wider the interval. For instance, a 95% confidence interval indicates that, if we were to repeat this analysis many times, 95% of the intervals would contain the true value. Note that this does not mean there's a 95% chance that the actual value lies within this range."
