The database index is a data structure that makes searching, inserting, updating and deleting records in the database table faster and more efficient. A good index makes sure that there is no large amount of data that need to be accessed during searching for a specific record. A well-indexed database eliminates the need to go through the whole database to access a specific record. Since the index points to the specific data required, the data retrieval time is faster. The index also helps in removing the need for extra space to store the data as each record has a pointer to it. This reduces the size of the database and makes it easier to manage.
