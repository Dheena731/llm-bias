Values in a confidence interval are chosen such that they can contain the parameter of the population with a certain probability, usually 95%. It is a range of values which is likely to contain the actual value of the population parameter. The narrower the confidence interval is, the less likely it is to contain the parameter value. The confidence interval’s width is directly related to the size of the sample, so it is bigger for smaller samples. The result is that confidence intervals of parameters are narrower for larger samples.
