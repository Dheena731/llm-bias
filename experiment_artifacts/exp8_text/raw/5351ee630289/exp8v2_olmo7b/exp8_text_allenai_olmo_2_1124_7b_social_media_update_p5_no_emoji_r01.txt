Context: You (and your team) are developing software for some users.


I'm just curious if the following sentence is grammatically correct:

We will be working on this project until the end of next week.

My initial instinct was that it cannot be correct, but I'm not sure why. It doesn't seem like there is anything ungrammatical about it. Is there some sort derived verb form that needs to be used instead?


This sentence is grammatical, but perhaps it might sound better with the word since instead of until that is used to indicate a period of time.

Another way to express this idea would be:

We will be working on this project until next week.

And another:

We will be working on this project through the end of next week.

So, we are saying here that we will be working on this project in the near future.
