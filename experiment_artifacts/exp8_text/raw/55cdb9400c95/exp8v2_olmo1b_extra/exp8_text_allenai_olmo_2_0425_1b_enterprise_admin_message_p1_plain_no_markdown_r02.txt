In Markdown syntax, code is formatted with subheader and <code> tags. Code can be surrounded by braces or blocks, which are separated by a pipe character (|).

    | This is a bomb.


Code is formatted using Markdown syntax.

Use these tags:

  • Headings: h1, h2, h3, h4, h5, h6
  • Bold text: **bold**
  • Italic text: _italic_
  • Code: ```code``` or ```{code}``
  • HTML tags: <h1>...<h6> and <a href...>
  • Links: <a href="link-name">... or <a>...
  • Table: ```table``` or ```{cellspacing="1" colspan="2" cellpadding="2" border="2"}```

To create tabs, use two consecutive spaces. To make a new line, use a space or two consecutive hyphens.

    | This is a tab. This is a line. The next line is another tab. The third line is a line with two spaces.
    | This is a tab. This is a line. The next line is another tab. The third line is a line with two spaces.

Markdown uses the start and end HTML tags to format text. These tags can be used anywhere in the text and do not need to be on their own line.

Use this to format headers:

    | Header one
    | Header two
    | Header three

You can also use the * asterisk* to bold text:

    | *This is bold* This is a title that is bold. 

Use the code tag to format code in your posts.

    | This is a code block.
    | This is also a code block.
    | It is now clear how I am using the code tag to format code.
