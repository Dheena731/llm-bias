Two-factor authentication (2FA) is defined as “the use of two or more independent security elements to verify user identity” and is now widely adopted across the world, including in the United States.

The United States Department of Homeland Security (DHS) offers this useful definition:

Two factor authentication is a process that requires a user to provide more than one form of identification. In many cases, two-factor authentication includes a second method of authentication that relies on something a user has (e.g., a token, mobile phone, physical object) and something a user knows (e.g., a password).
