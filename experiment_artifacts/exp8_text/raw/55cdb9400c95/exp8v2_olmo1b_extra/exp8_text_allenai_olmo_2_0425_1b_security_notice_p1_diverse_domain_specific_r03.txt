One of the most common misconceptions when it comes to password reuse is that everyone can reuse passwords as long as they have different passwords for different accounts. This is not true. For example, if your password reuse policy was to only use different passwords for different accounts and different services, then you have only limited protection against credential stuffing attacks. Consider the following example:

  • Password reuse policy: Use a different password on each site.
  • Password reuse policy: Use a different password for each email provider.
  • Password reuse policy: Use a different password for each social media platform.
  • Password reuse policy: Use a different password for each piece of software you use (e.g., the web browser or an app).
  • Password reuse policy: Use a different password for each website or app (i.e., all services).
  • Password reuse policy: Use a different password for each digital library, app, or digital platform (i.e., all services).

While these policies are all valid, the last example shows that it is easy to have a password policy that is inconsistent with itself. This means that if you reuse all of your passwords across all of your accounts, then your password policy is in fact weak, as it has not provided you with a measure of protection against credential stuffing attacks. For example, if your password is stolen and the criminal is able to obtain all of your accounts and apps, the criminal is able to attempt to log into all of your different services with the same password because you have not provided any extra protection.
