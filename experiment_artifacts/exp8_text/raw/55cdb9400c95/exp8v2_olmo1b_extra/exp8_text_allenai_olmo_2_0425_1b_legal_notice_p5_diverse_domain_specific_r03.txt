Beneath the description you should also make a direct quotation from the law that would apply to your context. The quotation should explain the specific linguistic features of that law, as well as how the law is applied within the context of the organisation. The quotation should also explain why the law is the best way to ensure users comply with the rules.

The quotation should be between 25 and 50 words. All quotations must be sourced or otherwise referenced. References should use superscripts to indicate where the quotation is referenced. References for quotations with straightforward sourcing should use an HTML anchor tag with the id attribute set to “anchor1”, and the name attribute set to the reference number. References for quotations with more complex sources should use an HTML anchor tag with the id attribute set to “anchor2”, and the name attribute set to the reference number. References for quotations with quotations should contain the name of the source, the page title, and the source’s URL. The quotation should describe what the source says, and should be included as a direct quote within the text. The following is an example of an acceptable quotation: ““If a 13-year-old is diagnosed as schizophrenic, the patient can be given drugs that are not produced for this purpose. At the same time, no pharmaceutical company will supply the drugs that are known to treat people like that.”[1] The most important feature of the quotation is that it explains the law that applies to the organisation’s purpose. In the example, it explains that Section 35 of the Copyright, Designs and Patents Act 1988, which applies to the UK, protects the secrecy of the drug trial, and allows “further restrictions on trade in [the] drugs when they are used for the treatment of mental disorders.” The quotation should explain how the law applies to the domain in question. In the example, it explains how the law applies to the context of a pharmaceutical company. It explains that it is not allowed to engage in a trade in the drugs in question, unless it is for the treatment of mental disorders. This needs to be clearly explained. It should be clear why this is the best way to ensure users comply with the rules. All sources should be referenced.
