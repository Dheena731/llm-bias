List every part of the account you’re modifying, referring to each one by its number in the numbering system used by the account (e.g., “Part 2” in the example below). For example, you might see the number 2 in your new text then refer to it in the account as “Part 2.” Note the use of number 1, which has been left untouched and will continue to refer to Part 1.

Use the numbering system used by the original account, or you can use the numbering system used for a specific kind of transaction, such as “Part 2: Payroll taxes.” You can use the same numbering system as the original account. The only difference is that the numbers are 1–9 in a separate table. Use small case letters (no italics). Use uppercase letters only to modify the account name, in the example below only “DHL” is modified.


Where do I find the original account number?

You can find the original account number on your recent statement or your most recent eCheck.

Is there a new account number for the account I’m modifying?

Yes, if you modify an account that has already been created, you’ll lose some or all of the original account’s history and data. You’ll need to apply for a new account number.

Is there a new account number if I’m using checks?

Yes, you’ll need to apply for a new account number if you’re using checks.
