**Database Index Explanation**

- **Store valuable data quickly** by storing a small pointer that points to the actual data record.
- Useful for fast data retrieval because it allows the database engine to skip unnecessary records.
- Reducing the time needed to access the data, improving performance.
- Inefficient if the index is out of date, possibly leading to unnecessary disk I/O.
- A simple, small data structure that stores metadata about how data is stored in other parts of the database.
- Prevents disk I/O by reducing the number of disk seeks needed to find a record.
- Allows faster data retrieval compared to a full table scan.
- Improving data access efficiency without significantly increasing storage space.
- Making the database more efficient and helping to prevent data inconsistencies.
