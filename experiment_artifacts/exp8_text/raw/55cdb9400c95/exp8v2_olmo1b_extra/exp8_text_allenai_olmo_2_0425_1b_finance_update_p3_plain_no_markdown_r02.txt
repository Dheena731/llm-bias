What is Formatting in Google Docs?

Formatting is the way that you choose to layout text on the screen. You can do this by choosing from a set of options or by using an AutoFormat feature. You can also apply text styles to text. This is done by choosing the desired font, size, and color from the Styles palette. This is useful when you need to make sure that all of your text is consistent, or you want to use the same formatting for different parts of your document.
