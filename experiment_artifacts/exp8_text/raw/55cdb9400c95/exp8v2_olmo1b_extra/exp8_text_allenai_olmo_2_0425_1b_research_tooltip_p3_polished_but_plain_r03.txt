Ordered lists

  • single-spaced
  • use decimal numbers
  • use 0 to 9 only for numbers
  • do not use a bullet point
  • do not use a number sign (#) or a hyphen (-)

Do not use dashes (–), hyphens (-), or underscores (_).

Do not use list markers such as asterisks (*) or numbers.

	*Single-spaced list item1
		*Second list item1
		*Second list item2
		*Third list item2

If a list item is indented four spaces:

	*Single-spaced list item1
		*Second list item1
		*Second list item2
		*Third list item2
		*Fourth list item2

For lists that use a second line to separate items, do not flush the indent of the last line. In these cases, the first line is flush left and the subsequent lines are indented four spaces.

  • Single-spaced list item1
  • Single-spaced list item2
  • Single-spaced list item3

Indent only one space.

  • 1
  • 2
  • 3
  • 4
  • 5

Consider using a Markdown editor with syntax highlighting to help you with indentation.

Item titles must be fully capitalized and start with a lowercase letter unless they are part of a quote or dash. (Usually, periods and dashes are represented by asterisks.)

For use in table, list, or code blocks, use two spaces to separate lines.

If a number is part of a list item, do not use bullet points.
