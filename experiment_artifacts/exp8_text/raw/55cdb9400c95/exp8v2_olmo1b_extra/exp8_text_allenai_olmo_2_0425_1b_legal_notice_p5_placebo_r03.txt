I have been doing some freelance web development, and for several of my clients, I have been using one of the commercial software packages, called Server Side Include. This is a wonderful piece of software that allows me to easily output HTML code to the client, and then integrate that code into their website using special HTML tags called Server Side Includes.

Well, the client has now been using Server Side Includes for a few months, and has now requested that I modify his website so that it is more accessibly. He does not understand the concept of Server Side Includes, and thinks that they are a form of HTML code. This is why he wants my website replaced. I think that it will be easier to explain it to him in a little more detail in a friendly letter. So, if you have a moment, could you please give me the necessary information, which I will need to write such a letter? Please let me know how you like this form letter.

Thank you,
