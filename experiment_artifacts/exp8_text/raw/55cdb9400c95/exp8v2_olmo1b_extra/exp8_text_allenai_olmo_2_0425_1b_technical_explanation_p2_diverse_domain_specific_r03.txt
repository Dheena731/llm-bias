The key concepts here are that there are multiple ways to say the same thing, and saying it in a way that emphasizes the only relevant keyword is more specific. Since we use the word "search" as a search query (as in "search the database for items whose names include the word X"), saying that the database has a search engine is redundant and just adds noise.
