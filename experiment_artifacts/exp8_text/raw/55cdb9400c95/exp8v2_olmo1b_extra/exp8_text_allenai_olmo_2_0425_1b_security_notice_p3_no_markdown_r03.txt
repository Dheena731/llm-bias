Text formatting

  • Use asterisks to indicate emphasis, e.g. **bold**.

  • Use underscores to indicate inline code, e.g. `code`.

  • Use horizontal rules to build a table, e.g. this line is a table line.

  • Use ended lines to indicate paragraph breaks, e.g. this is a paragraph.

  • Use * in web links to indicate a link, e.g. https://*.*.

  • Use single-caps in URLs to indicate a link https://*.

  • Use **CE** in URL to link to a human-readable version of a URL https://*.

  • Use * in text to mark a range of numbers, e.g. 1-2, A-5, 2-3 etc.

  • Use % in URLs to escape a % character, e.g. %2B to create a + symbol, %0A to create a space.

  • Use the tilde (~) character, followed by a space, to create a horizontal rule character. This is interpreted as a line break in a text file.

Web Linking

Use links to href attributes on your links. For example, you can link to a human-readable version of a URL https://*.

You can also link to a specific text string in your text, e.g. you can link to a specific part of a URL https://*. When you use the link, the browser will retrieve the URL, and replace * with text in the URL, e.g. https://*.

Linking to a URL can be important in some contexts for instance, if you want to tell the reader that the URL of this content is in a particular format. Linking can also be useful to show the reader where your information comes from or to ensure they have the correct context when retrieving the information they are reading.
