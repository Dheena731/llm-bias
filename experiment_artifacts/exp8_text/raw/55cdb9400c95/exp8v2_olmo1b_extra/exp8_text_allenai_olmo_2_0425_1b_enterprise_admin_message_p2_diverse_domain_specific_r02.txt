Quality Assurance Manager

You will be responsible for the quality of our products. We expect that your skill set will include the following skills:

  • Knowledge of standard software testing techniques. You should be able to run unit testing, regression testing, integration testing, system testing, deployment testing, security testing, and alpha/beta acceptance testing.
  • Knowledge of software projects planning and tracking.
  • Experience in the process of project management. You should be able to do the following:
    1. Plan and manage complex software projects.
    2. Sustain the effort and deliver appropriate products on time.
    3. Receive full and detailed information from the end users.
    4. Keep project deadlines and requirements in mind.
    5. Plan and manage the lifecycle of the project.
    6. Manage relationships with stakeholders.
    7. Manage project manpower.
  • Experience with user acceptance testing (UAT) methodology.
  • Ability to convince other stakeholders about the benefits of a new product.
  • Knowledge of standard documentation and project tracking methodologies.
  • Knowledge of DevOps, CI/CD, and Agile methodologies.
  • Knowledge of standard software development best practices.
  • Experience in Scrum and Kanban methodologies.
  • Experience in software engineering.
  • Experience with Agile environments.
  • Experience with various programming languages.
  • Knowledge of web and cloud technologies.
  • Expertise in writing requirements, design documents, system documentation, bugs reports, and requirements engineering.
  • Knowledge of formal and informal communications techniques.
  • Knowledge of software development approaches, such as agile methods, waterfall methods, and functional testing.
