4.3. Mastering your agenda

Your agenda should be well-structured, containing the main points and any special considerations. It can be of any length, but try to keep it to the point. If you have to list a lot of details, consider writing an outline with bullet points and numbering your items.

4.3.1. Assign tasks and stages

Your agenda should clearly distinguish between tasks and stages. A stage is a single, relevant topic, which might include subtopics so you can break down a task into smaller tasks. A task is an action you have to perform, such as:

  • Call a customer
  • Perform a test on a product
  • Buy some software

You can use the tasks and stages table below for your agenda.

Tasks Stages Tasks Stages
Manufacture a product Test the product
Write a blog post Build a website
Program a robot Perform a test run

4.3.2. Assign tasks

Putting milestones and tasks into an agenda is a great way to prioritise tasks, especially if you need to split large tasks into smaller ones. However, you shouldn’t hesitate to assign priority to certain tasks over others. Remember: all tasks are important. Some tasks might seem boring or menial, but they are still necessary for the project to be completed.

4.3.3. Use a visual outline

When you’re preparing your agenda, you might be tempted to write your tasks and tasks stages in a list. Don’t! Use a visual outline instead, to make it easier to follow the progression of tasks and stages.

4.3.4. Use a system

You can keep a system to track your tasks and milestones. For example, you could use a three-column calendar to do this.

  • The left column has columns for each day of the week. On the left, write the date. On the right side, write the name of the day. For example, if you’re working on one day’s task, write “Monday 12:00”, and then on Wednesday, “Wednesday 12:00”.
  • The main column is for the task or stages, and you can start each one with its own bullet point. For example, on Monday, you might write “Monday test the product” and then on Wednesday, you might write “Wednesday repeat the test on Monday 7:00”.
  • The right column is for the details of the task or milestones, like information about how much time each stage will take.

4.4. Manage your projects

4.4.1. Manage your priorities

Making a priority list of tasks and stages is very important. You might spend the whole day, week or month working on one of your tasks, but you should still ensure you’re working on the most important task.

4.4.2. Put deadlines in perspective

Don’t put deadlines everywhere, because they might distract you from the important tasks that you need to complete first. Instead, keep the deadlines visible on a digital wall chart or calendar.

4.4.3. Focus on tasks

If you find yourself without any tasks to work on, it can be hard to start. To avoid this, you should plan to work on the most important tasks first, then other tasks as you find more time. But make sure you don’t multitask, or you might overwhelm yourself.

4.4.4. Break up your day

If you’re multitasking, it might be hard to focus on one task for long periods. Instead, try to break up your day to do different tasks one after another. This can make it easier to tackle the most difficult tasks.
