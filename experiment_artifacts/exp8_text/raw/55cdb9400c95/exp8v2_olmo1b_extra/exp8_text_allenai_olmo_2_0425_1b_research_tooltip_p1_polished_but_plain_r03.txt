Writing a tooltip that explains live data

In a linked tool, such as a spreadsheet, an image, or a calendar, you can write the tooltip in the body of a cell or a table row. If you do this, make sure that the data source is live. See Live data sources for information about this.

Writing a tooltip that explains a search result

For search results, our search result description is a tooltip that tells the user about the reason that a given data source or data point was shown in the search. We use a custom approach (that is, not a simple table of data points) to ensure that the description is both meaningful and concise.

Writing text that explains a visual element

We use tooltips and explanation tables to write descriptions for visual elements such as arrows, lists, border boxes, and color gradients. We always write the text in the body of a table, with no extra text outside of it. The table describes the data for each visual element.

Writing tooltips for links to other tools

We write tooltips that explain what a link does when it takes the user to another tool. We follow the same guidelines for the tooltip as we do for other tools that display data.

For example, the tooltip text might say:

Take me to the full version of our tool.

Writing tooltips that explain a chart

We write tooltips that explain the details of a chart when it contains visual elements such as bar graphs, pie charts, line graphs, and scatter plots. We follow the same guidelines as we do for other tools that display data.

For example, the tooltip text might say:

Here's an example of a pie chart. Here's an example of a pie chart.
