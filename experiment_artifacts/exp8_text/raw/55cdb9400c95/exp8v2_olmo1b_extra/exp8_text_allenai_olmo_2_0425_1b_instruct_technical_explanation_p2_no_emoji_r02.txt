A database index serves as a lookup table that speeds up data retrieval by allowing the database engine to find specific records more efficiently than scanning the entire table. It does this by storing alongside table data pointers to the locations of the data that are most likely to be requested next. This is especially helpful when the primary key or frequently searched fields in the table are large and/or complex, making direct searches slow and inefficient. Indexes help by reducing the number of disk reads, thereby speeding up access times and improving the performance of complex queries.
