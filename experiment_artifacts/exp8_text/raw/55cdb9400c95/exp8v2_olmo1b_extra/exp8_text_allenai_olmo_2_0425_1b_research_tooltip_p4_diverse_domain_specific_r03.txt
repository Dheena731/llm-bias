Now that we know what our app can do, let’s create a simple app with it. We’ll learn how to create a new application in Python and a new object in the application’s objects module, which will have the objects we created before.

Start a new project in your code editor. Copy the following text and save it. This is the code for the new app.

import Pensieve
import Pensieve.pensieve

class Login(object):
    """The login class that will implement the login functionality."""

    def __init__(self, login_email, login_password):
        """The __init__ function initializes the object with the login email and password."""

        Pensieve.pensieve.Login(self.login_email, self.login_password)

    def sign_in(self):
        """The sign_in function runs when the user is ready to login."""

        Pensieve.pensieve.Login(self.login_email, self.login_password)

    def logout(self):
        """The logout function runs when the user is ready to log out."""

        Pensieve.pensieve.Login(self.login_email, None)

Note that the Pensieve.pensieve module is imported here. This gives us the functionality for the Pensieve library.
