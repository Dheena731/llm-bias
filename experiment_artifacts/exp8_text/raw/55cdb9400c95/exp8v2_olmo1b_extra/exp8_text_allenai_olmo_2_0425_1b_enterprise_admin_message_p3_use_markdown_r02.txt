# VPN-Client-Change

## Subscriber Features

Here are the features related to the subscriber.

- **Full SSL/TLS support**
- **Renewable IP**
- **Server support**

### Provider Features

Here are the features related to the provider.

- **Server monitoring**
- **Server health features**
- **Yubikey secure key support**
- **Network monitoring**
- **Renewable IP**
- **Server support**
- **Caching support**

## Other

Besides the above features, you can use this VPN client in the following ways.

- **Mobile**
- **Windows 10**
- **Windows 8**
