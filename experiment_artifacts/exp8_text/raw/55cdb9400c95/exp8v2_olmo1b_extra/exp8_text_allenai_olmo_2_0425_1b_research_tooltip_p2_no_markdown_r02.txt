Tip text: A confidence interval is a range of values that is likely to contain the true value of a parameter with a given level of confidence. For example, a 95% confidence interval is a range of values that is likely to contain the true value of the mean population proportion of individuals who are intoxicated by alcohol 95% of the time. Confidence intervals are calculated from sample statistics and can be used to estimate the value of a parameter for the population.
