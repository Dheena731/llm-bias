A database index is a structured collection of data values that is used by the database management system (DBMS) to speed up database lookup operations. Essentially, an index acts as a roadmap or table-level map for the database, allowing the DBMS to find specific data more quickly than it would using a full table scan. When a query asks for a specific row, the DBMS first checks the index to see if a match exists near the requested data. If a match is found, it collects the necessary information from that location and performs the main query operation more efficiently than if it had to scan the entire table. Indexes are especially useful for data retrieval, query optimization, and maintaining data integrity.
