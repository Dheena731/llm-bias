There are a wide variety of security measures that you can implement in your workplace to manage password reuse and other password management problems. You can use a password management tool that generates random passwords for you, you can employ a password hash generator, or you can create a password reuse policy and educate your employees about the dangers of reusing (or not reusing) passwords. You might also want to look at the OWASP Top 10 list and consider implementing their recommendations along with your own.

Why Third-Party Password Managers Are a Bad Idea

Many security professionals are advocating the use of third-party password managers, but they should be avoided. A password manager is a single source of truth for all of your password credentials. It stores all of your passwords in one place so that you will only have to remember one master password for your username-password pair, which is whatever your password manager uses. It also means that a single breach could potentially expose your credentials to hackers. It’s a little like having a software system that has a single point of failure.

We encourage you to use a password manager for storing your user-password pairs and other secrets. But when it comes to password reuse, you should avoid using a password manager to create new passwords for you. Instead, it’s better for password reuse to create new password using a password manager, but to create new credentials from scratch for each password in your system. This is especially important when you are creating credentials for passwords locked away in your password manager, such as your username-password pairs. Make sure to change them to different passwords and then create new ones for all of your leaked credentials. If you’re using a password manager, make sure you are using the option to temporarily store your passwords in a new directory and then deleting them when you have finished using them.
