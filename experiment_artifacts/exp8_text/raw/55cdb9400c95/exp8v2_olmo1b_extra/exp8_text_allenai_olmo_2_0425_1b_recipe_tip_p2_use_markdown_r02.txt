  1. Make sure the herbs you're storing are fairly dry (not soggy).

  2. Place the herbs in a sealed container.

  3. Keep the container in a cool, dark place.

  4. Remember to write down the time the herbs were stored so you can date them.

  5. Set an alarm for a few weeks to check on the herbs when you need them.

  6. If you run out of herbs, you can make a simple recipe and use them when you need them.
