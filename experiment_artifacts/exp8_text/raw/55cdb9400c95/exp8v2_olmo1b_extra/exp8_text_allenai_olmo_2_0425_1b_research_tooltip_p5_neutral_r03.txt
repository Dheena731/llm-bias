Don't do it. It's not something that anyone will ever want to look at. Everyone will always want to see the end result.

I think that, for one, it's bad to set up a workflow that is so repetitive that it takes two to three times as long to get something done. For instance, you might want to use a form to add new employee data into a database, and then validate that employee data to see if it's correct, and then save that data to the database to be added to the employee table. By putting it all into a form, you are essentially limiting yourself, because you don't know if you got everything right, and you don't know if you need to add more fields to it.
