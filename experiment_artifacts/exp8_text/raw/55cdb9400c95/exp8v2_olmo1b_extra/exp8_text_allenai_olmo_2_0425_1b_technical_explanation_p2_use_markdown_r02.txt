A database index is a data structure to speed up database query performance.
It works by efficiently storing and mapping one or more columns (or sets of columns) to an array of key/data pairs.
The key is the unique value or combination of values that represents the column.
The data is a byte array that represents the relevant data for that key.
The final benefit of an index is that it makes queries perform better by returning results faster.
You can think of an index as a way to take all of the rows and convert them into smaller chunks that are easier to work with.
