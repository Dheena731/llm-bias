Preview your work as you write it to see if your formatting is right.

As you write, check that the following items are correct:

  • What item are you discussing?
  • What is the item's purpose?
  • How is the item introduced?

As you write, check the following items:

  • How is each item organized?
  • Are the details and examples clear?
  • Is the approach for each item considered? Is it the best approach for the intended audience?
  • What are the strengths and weaknesses of the approach?
  • Is each item well-written and clear?
  • Are there any terms that need to be defined?

Write a summary statement for each item. Summaries should be concise. You should use your own words to paraphrase the material in the item.

Include one or more photos, graphics, or videos. If you use photos or graphics, write captions and include bibliographic information. Include a link to on your website. If you use a video, include a URL.

Include examples of how the item applies to the reader. For example:

Example item: "This is a list of the items in a text, in order, and the item should be numbered. I have used the numbering in the following example.

Example item: "To study an item, I would review the item once, then write about the item, and finally reference the item in a subsequent assignment."

Example item: "To write about the item, I would provide personal examples, and to reference the item I would refer to the item in a related assignment."
