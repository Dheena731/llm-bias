Sets and querying

The set operator is one of the most useful operators in the SQL language, used to select a subset of rows.

Drop a query from the Databricks SQL Editor by right-clicking on it and selecting 'Drop Query'.

Here, we'll create a simple set-based query. We'll select all rows from the table where Country = 'Israel'. This will result in '0' in the column 'Country'.

Query: select * from country select * from country where Country = 'Israel'

We can then export the results as JSON.

Query: set Country to 'Israel'; export results as json
