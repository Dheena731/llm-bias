The compare method does the following:

  • Compute the indexes by index number, then use the primary key index as the first index and the unique key index as the second index.
  • The compare method uses the first unmodified index, and does a string comparison between the text contents of the two values.
  • If the index contains more than one value, it cannot find a unique value and cannot compare the text contents. (For example, if there is an entry with the key "x" in the first index, but the value is "y", it will not work.)
  • If the keys in the index are the same, but the values are different, it cannot find a match (for example, if there is an entry in the index "x" with the key "x", but the value is used in another index).
