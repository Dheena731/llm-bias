A dataset filter is a piece of the UI that lets you search through a set of datasets. For example, if your tool is a social network, you might have a filter that let users filter all entries from a particular time zone.

A dataset filter is a data descriptor. It's not a visualization – it's a piece of the UI. That means that dataset filters should be concise: shorter, clearer, and more actionable. You also want to make sure that if the user clicks on the filter, the tooltip tells them exactly what they can do with that filter.

Tip: When you're designing a dataset filter, ask yourself whether a user needs all the information a dataset filter provides. For example, if a dataset filter displays Spreadshirt's data for the US, you probably don't need to show the company's website address. You can only reveal that information when the user clicks on the filter.

Tip: Always make sure that you know what the filter is doing. Make sure that when you look at the filter, you can see exactly what it will do. If you think that your users don't need all the information, try to figure out different ways of presenting that information to them. Trying different ways of presenting the same information might reveal things that you never knew.
