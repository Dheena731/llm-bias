Yes, you can do that. You can use the Markdown syntax in plain text, such as headers and bullet points, and any of the inline codes are just a different way to enter the same thing. One such way, the single code below, is to use sans serif fonts. If you want to use a body text font, just add the special code to the top of your text and the font will be the body text font. You can check out the standard Markdown examples to learn more on how to use such formatting.
