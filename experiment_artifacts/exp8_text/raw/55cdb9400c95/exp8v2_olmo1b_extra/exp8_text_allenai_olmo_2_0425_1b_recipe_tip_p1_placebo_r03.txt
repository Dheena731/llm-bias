The food is delicious but the appetizer is dry. (source)

The main point of that sentence is that the appetizer is dry. The surrounding writing does not support this, but that is the main point.

The food is delicious, but the appetizer is dry. (source)

This sentence lacks the main point that the appetizer is dry. (For a particularly dry appetizer, this sentence might work.)

This food is delicious but the main point is that the appetizer is dry. (source)

The main point is that the appetizer is dry, but this sentence still lacks the main point. (This sentence might be fine if the main point is that the appetizer is dry and the food is delicious.)

A good way to find a good main point is to write a summary using the following sentence structure:

  1. The food is delicious.
  2. The appetizer is dry.
  3. Therefore, the main point is that the appetizer is dry.

(Remember, writing summaries is hard. You need to be careful to not make any obvious mistakes.)

Order the writing to improve the main point. To order a sentence, read it from the beginning, then stop and think about whether the order adds emphasis, adds credibility, or adds emphasis and credibility. It is very common to move word order to make a sentence clearer. For instance, the sentence above could be rewritten as:

  1. The food is delicious.
  2. The appetizer is dry.
  3. Therefore, the main point is that the appetizer is dry.

However, sometimes the order of the sentence adds emphasis or credibility. (Consider the following sentences, for example.)

  1. The author of this book is a wonderful writer.
  2. The author of this book is a wonderful writer. (source)
  3. The author of this book is a wonderful writer, so please buy it!

The last sentence is an example of a sentence that is longer than what is strictly necessary. Underline the main point. This is the main point, so it will be a good line as long as it includes the main point. (This conversion is one I use often. I often write a sentence, then underline the main point.)

  1. The food is delicious.
  2. The appetizer is dry.
  3. Therefore, the main point is that the appetizer is dry.

(For those who are familiar with grammar, the distinction between independent clauses (main points) and dependent clauses (information the reader needs to know) is important. For instance, in the last example, the second clause (“so please buy it”) is a dependent clause that depends on the first clause (“the author of this book is a wonderful writer”) for its meaning. In contrast, the first clause is an independent clause, its meaning is clear without the second clause.)

Use the order of ideas to improve writing. Sometimes the structure of a sentence is just not working. This sentence below is a common example:

  1. However, in our culture, we tend to overestimate the importance of remaining alive.
  2. Even though we tend to overestimate the importance of remaining alive.

The problem is not the two ideas. The problem is the order of the sentences. The second sentence is a “top down” sentence. The problem with a “top down” sentence is that it depends on the first part of the sentence. (It depends on the first part of the sentence in particular, because the subject of the second sentence is “we.”) The problem is that it is difficult (even impossible) to infer an order in a “top down” sentence.
