Sending Mails

The Sneaker class provides an API to send emails from an application. There are two methods that are used to retrieve the email queue data:

  • sendEmail()
  • sendEmailWithTemplate()

The sendEmail() method takes two arguments:

  • the context object
  • template file

The sendEmailWithTemplate() takes one argument:

  • template file (string)

The sendEmail() method will send the email to email recipients with the provided context object. The sendEmailWithTemplate() will be used to send the email with a template file included.

Sending Emails

Sneaker provides an email template generator that allows the user to easily create a template for sending emails. This template generator allows for content type customization and email subject customization.

email_template = Sneaker.template("emails/email")
require 'email'

# username must be set as a data source
username = ENV['EMAIL_USERNAME']
email_template["from"] = "from@example"

# username must be set as a data source
email_template["from"] = "from@example"
email_template["to"] = "to@example"

# email template body
email_template["content"] = 'Hello %s!'

# email subject
email_template["subject"] = 'Find My Sneaker'
