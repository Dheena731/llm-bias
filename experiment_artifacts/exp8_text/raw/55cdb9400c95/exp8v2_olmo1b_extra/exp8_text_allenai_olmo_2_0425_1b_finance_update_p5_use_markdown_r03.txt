### The Problem

Also we need to make sure that the project is very easy to use for the first time. The following are the steps we need to take to get the project ready for production 1. Find some more developers to help us with the production stuff.

### A quick start

Let's quickly get started and create your first simple Brainstorm project. 1. Start a new project in Brainstorm. 2. Choose `New` under `New project` 3. Choose any of the templates. 4. In the `Create project` objective, choose the `CloudFormation` template. 5. The CloudFormation template that you just created is actually going to create a CloudFormation template that will get our brains running! 6. Choose `Edit` 7. Try to change the title of the project. 8. You can also change the name of the default package and the name of your repository. 9. Enable the instance. 10. Create a database. 11. Name the database and make sure `root` is your default user for the database. 12. Again, try to change the name of the database, the default user and the database name. 13. Click `Start` 14. Click on the `View Code` tab. 15. Copy the code and paste it in your editor.
