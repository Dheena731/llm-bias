General notes

As you can see, it's not a very complicated process. But making a mistake with the wrong password can lead to trouble.

There are a few things to take into consideration:

  • You probably want to set up a strong password for your sudoers file
  • If you lose a file, you can change the permissions on that file, but you'll have to recreate the file
  • The output from visudo may be long. So, you may want to limit the listing to only those lines you care about

You can find the full man page for visudo at man visudo
