Use headings

The notice should be structured so that the most important information appears first. This is calling for a heading.

Use a heading to create the outline for your document. A heading is the first level of a heading. There is a heading level one, heading level two, and so on.

A heading level one is created by adding H1 to the heading. This is used by editors when they are composing a document.

A heading level two is created by adding H2 to the heading. This is used by copy editors when they are checking the text.
