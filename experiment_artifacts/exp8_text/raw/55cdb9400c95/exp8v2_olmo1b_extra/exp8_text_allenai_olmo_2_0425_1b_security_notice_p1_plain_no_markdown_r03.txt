Password Management

Secure passwords are key to protecting your computer. We recommend using strong passwords that are at least eight characters long.

With an ever-increasing number of programs, sites, and services, it's hard to remember every password you use. This is where password managers come in. A password manager keeps the passwords in a secure vault. You can download one or more of these managers to your computer, smartphone, or tablet. These managers typically allow you to generate, store, and manage passwords, as well as provide information about the last time you logged into a program or service.
