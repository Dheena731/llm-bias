1.4.4  Importance of Text Classification

Importance of Text Classification

There are many ways to classify text. In this exercise, we use two types of classification algorithms: a random forest algorithm and a bag of words algorithm. Both algorithms were specifically designed to be used for classification of text-based data, but we are not necessarily limited to them.

1.4.5  Choosing a Text Classification Algorithm

Choosing a Text Classification Algorithm

This exercise should help you determine which algorithm to use.

  1. To get started, run this Python script and clone the repository using git in the Jupyter notebook.
  2. Try to complete it to see how this algorithm works. If you are unsure, you can always run the script on any diagnostics you have, and it will give you an error message with the details. For example,

    File "/Users/brucevirenccode/R/Cognitive-Exercises/ImageProcessing/MachineLearningTutorial/RoomTemperatureData.py", line 18, in <module>

    from sklearn.ensemble import RandomForestClassifier

    ImportError: No module named 'sklearn.ensemble'

    Depending on your system, you may need to install the extra packages like: sklearn.ensemble, scipy, sklearn.preprocessing, or some of them from github.

  3. Understanding the algorithm needs some reading. You may want to read the documentation or the source code of the algorithm. You may also want to try to implement other algorithms and compare them to the random forest.

1.4.6  Assessing the Algorithm

Assessing the Algorithm

Understanding the algorithm is important for the next steps, so work on one of the three exercises below. You can also complete the remainder of the exercises if you have time.

  1. Complete the summary quality check. This is a quick way to assess how the summaries are performing. You can run it in the Jupyter notebook or the Python script, or both. You will see that there is a difference between the summary scores, which is how we will start the discussion of the summary generation in the next step.

    To run the summary quality check, you may need to change the file path in the script, which is as follows:

    input_dir = "/Users/brucevirencode/R/Cognitive-Exercises/ImageProcessing/MachineLearningTutorial/"

  2. Complete the summary quality check algorithm. Run it in the Python script or the Jupyter notebook and report the results.
  3. Continue working on the rest of the first exercise and submit it when you are done. When you are done, you should have three summary quality scores representing
    1. the mean summary score for the original images collected by the camera and
    2. the mean summary score for the images collected by the webcam and
    3. the mean summary score for the images generated by the algorithm.
