What is a database link?

A database link is a row in the database that references another table in the same database. The database link appears in the source table as a link to the target table. When the source table is updated, the target table's linked rows are updated automatically. The original values are not updated as in a SQL INSERT statement.

A database link defines a one-to-many relationship. You can have a database link with any number of source tables. The target table can be a linked table or a table that doesn't exist. You can also create database links to external databases and connect them to SQL Server. A database link can be created in either the Database Link Wizard or the Database Link Properties dialog box.
