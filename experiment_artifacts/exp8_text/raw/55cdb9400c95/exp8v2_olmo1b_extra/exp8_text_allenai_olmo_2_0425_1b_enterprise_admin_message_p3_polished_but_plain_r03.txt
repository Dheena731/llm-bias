If you are writing a new article, write it in Markdown format first. This will ensure that your article follows the formatting rules for that article type. You can then copy the text into the editor, format it using the tools in the editor, and use them to import it into the article.

If you are writing an article that is included in Codecademy, and you want to make use of Codecademy-specific formatting tools, use the assets:tags parameter. Include the markdown language name (markdown, markdown2, etc.) and the version number for the markdown parser used to format the article (e.g., markdown 2.0, markdown 2.1, etc.). For example:

a:  
    ## The Formatting Guide  
    * Codecademy's Markdown Syntax
    

This means that all articles will also have the following tags as pointed out below:

[user-info]   Your name, username, etc.
[audio]     <video> tags
[code]       <pre> tags
[gallery]   <div> tags with image links
[head]       Head with a <title> tag
[history]   History for the article
[img]       <img> tags
[link]      <a> tags
[meta]      <meta> tags
[ol]       Open a numbered list
[ol>       List items within <ol>
[other]     List items that are not nested in <ol>
[song]     Open a section that has a <div> tag

If you are writing an article that is included in Codecademy, but you want to format the article using markdown syntax that is not part of the Codecademy defaults, use the markdown syntax for that codecademy version and use the markdown syntax that is not part of the defaults. For example:

markdown 2:
a:

   * Codecademy's Markdown Syntax

    <p>You can write any text you want.</p>
