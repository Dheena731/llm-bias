This is an example of a tooltip - click on an object in a data set in any of the tool's views and you'll see the tooltip.

The tooltip is shown as you hover over an object. It provides an explanation of the term which was selected. (Note that the tooltip is only shown if you already have selected the term - if you still have the object selected, no tooltip will appear.)

For example, in the following example, if I mouse over the term "New York", the tooltip is shown:

enter image description here

I've chosen to use a simple style of tooltip - the text is white, the word "New York" is in a blue box, and under the blue box is a black outline box. If I instead used a tooltip style that shows a list of link options, it would look something like this:

enter image description here
