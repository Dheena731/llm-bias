Use a decimal point to separate numbers.

Example

Use a decimal point to separate numbers from values (like $ currency symbols) rather than an underscore.

Example

When including a variable in your value, use a decimal point to separate the variable from the value. For example, <INPUT TYPE=submit VALUE="$username" onblur="somefunction()">.

Use a period to separate identifiers.

Example

Use a period to separate identifiers. For example, you could include a variable in your value like this: <input type="text" name="bob" value="taco" onkeystroke="\[value\]"/>.

Examples

Use a period to separate other types of values.

Example

Use a period to separate other types of values. For example, you could include a range of values in your value like this: <input type="radio" name="show" value="1" value="2" value="3" type="radio" onkeystroke="\[value\]"/>.

Separate amounts in decimal format

Example

Use a decimal point to separate amounts in decimal format. For example, one output value could be <input type="number" name="amount" value="$50.00" onkeystroke="\[value\]"/>.
