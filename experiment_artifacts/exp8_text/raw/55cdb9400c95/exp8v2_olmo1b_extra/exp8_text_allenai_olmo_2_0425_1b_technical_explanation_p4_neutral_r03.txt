How to get started

In the next section, you will learn how to perform a code review of your site. When writing your code, you will usually find a lot of references to the different calls to the API, and what the API returns. We will call these things API references and API calls. We will use the terms calls and references interchangeably. A call is the act of running a method or function that the API provides or a reference is a call to the API.

In this task, you will determine how to improve your code based on API references and API calls. Refer to the guide to System calls and External Dependencies for help with this task.

How to get started

  1. After installing the Node.js SDK, open Node.js's REPL and run the following code:

    node index.js
  2. Enter the following command:

    node node_modules/expo/bin/expo run

    This will start the Expo app.

  3. Go to the page for the article, you want to review. If you are working with the saved app, you should go to the Discussion Page. If you are working with the Expo app, you can simply go to the article you want to review.

  4. As you look at the page, you will notice a lot of API references and API calls that are not being used. If you are reviewing a Chrome app, you will notice that the app is using a lot of calls to the web server when it is offline.
