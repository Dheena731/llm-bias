An API rate limit is a rule enforced by an application programming interface (API) that restricts the number of requests a user or system can make within a specific time frame. Its primary purpose is to protect the API's infrastructure from excessive traffic, ensure consistent performance for all users, and prevent misuse. Rate limits are typically expressed as a maximum number of allowable requests per minute, hour, or day. When a requester exceeds this threshold, the API stops accepting new requests until the time window resets, usually sending back an error response to indicate the limit has been reached.
