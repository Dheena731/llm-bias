An API rate limit is a restriction set by a service provider that caps the number of requests a client application can make within a specific timeframe. For example, a service might allow one hundred requests per minute from a single user or IP address. If a program attempts to send more than the permitted amount, the server temporarily blocks additional requests and returns an error indicating that the threshold has been exceeded, requiring the user to wait until the time window resets.

Providers enforce rate limits primarily to ensure system stability, security, and fair access for all users. Without these boundaries, a single malfunctioning script, sudden traffic spike, or deliberate cyberattack could easily overwhelm server resources, causing slow response times or total outages for everyone else. By setting predictable caps, companies protect their infrastructure from abuse, manage operational costs, and encourage developers to build efficient, well-behaved applications.
