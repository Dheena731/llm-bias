A database index is a separate data structure that the database maintains alongside a table to speed up searches. Without an index, finding rows that match a condition, such as all customers in a given city, usually requires the database to scan every row in the table one by one. An index instead stores the values of one or more columns in a sorted or otherwise searchable form, along with pointers to the rows where those values appear. The database can then consult the index to jump directly to the matching rows, much as a book's index lets a reader go straight to the pages on a topic rather than reading the whole book.

The benefit comes at a cost. Indexes take up additional storage, and every insert, update, or delete on the table must also update the relevant indexes, which slows down write operations somewhat. For this reason, databases are typically indexed on columns that are frequently used in searches, joins, or sorting, rather than on every column.
