A database index is a separate data structure that the database maintains alongside a table to speed up data retrieval. Much like the index at the back of a book, it lets the database find rows matching a condition without scanning every row in the table. Indexes are typically built on one or more columns, and they store the indexed values in a sorted or hashed form along with pointers to the corresponding rows. When a query filters, joins, or sorts on an indexed column, the database can use the index to locate the relevant rows quickly. The tradeoff is that indexes consume additional storage and slow down write operations such as inserts, updates, and deletes, because the index must be kept in sync with the table.
