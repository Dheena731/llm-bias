A database index is a separate data structure that the database maintains alongside a table to speed up data retrieval. Much like the index at the back of a book, it stores the values of one or more columns in a sorted or organized form, along with pointers to the rows where those values appear. When a query filters or sorts on an indexed column, the database can use the index to locate matching rows directly instead of scanning the entire table. The trade-off is that indexes take up additional storage and must be updated whenever rows are inserted, updated, or deleted, which can slow down write operations. For this reason, indexes are typically created on columns that are frequently used in search conditions, joins, or ordering.
