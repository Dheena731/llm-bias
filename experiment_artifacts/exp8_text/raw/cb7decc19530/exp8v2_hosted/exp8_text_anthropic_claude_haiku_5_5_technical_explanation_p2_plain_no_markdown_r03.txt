A database index is a separate data structure that helps the database find rows quickly without scanning an entire table. It works much like the index at the back of a book: instead of reading every page to locate a topic, you consult the index, which points you directly to the relevant pages. In a database, an index is typically built on one or more columns, and it stores those column values in a sorted or tree-like arrangement along with pointers to the matching rows. When a query filters, sorts, or joins on an indexed column, the database can use the index to jump straight to the needed data. The tradeoff is that indexes take up additional storage and must be updated whenever rows are inserted, changed, or deleted, which can slow down write operations. For this reason, indexes are usually created selectively, on columns that are frequently searched or used in conditions.
