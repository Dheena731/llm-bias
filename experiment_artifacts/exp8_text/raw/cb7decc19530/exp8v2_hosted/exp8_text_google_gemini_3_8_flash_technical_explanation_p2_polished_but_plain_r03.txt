A database index is a specialized data structure designed to accelerate the retrieval of information from a table. Conceptually, it functions much like the index at the back of a reference book. Without an index, a database must examine every row sequentially to find a match, a process known as a full table scan that becomes increasingly slow as data accumulates. When an index is created on a specific column, the database organizes those values into an ordered, easily searchable format alongside pointers to the corresponding full records on disk. This enables the system to locate target data directly, bypassing the vast majority of irrelevant rows. While indexes dramatically improve search and query performance, they require a deliberate trade-off. They consume additional storage space and introduce overhead during insert, update, and delete operations, because the database must keep the index updated whenever the underlying data changes.
