Starting Monday, March 3, the VPN client will be updated to version 4.2. The main change is that the client now reconnects automatically if your network connection drops, so you should no longer need to sign in again after switching between Wi-Fi and mobile data. The login screen also now uses your company single sign-on, so you will use the same credentials as your email. Please install the update from the company software portal before April 1, when the older version will stop working. If you run into problems during installation or sign-in, contact the IT help desk and they will walk you through the fix.
