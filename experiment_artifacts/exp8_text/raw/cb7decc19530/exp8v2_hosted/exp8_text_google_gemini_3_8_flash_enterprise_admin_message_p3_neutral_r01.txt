**Subject:** Important: Upcoming change to our VPN client

Hi team,

To improve network security and performance, we are transitioning to a new VPN client, **[New VPN Name]**, effective **[Date]**. 

**What you need to do:**
* **Before [Date]:** Download and install the new client using [this link / Software Center].
* **Setup Guide:** Step-by-step instructions can be found [here].
* **Old VPN:** The current VPN ([Old VPN Name]) will be decommissioned on **[Date]**.

If you run into any issues, please reach out to the IT Helpdesk at [Contact Info].

Thanks,  
[Your Name/IT Department]
