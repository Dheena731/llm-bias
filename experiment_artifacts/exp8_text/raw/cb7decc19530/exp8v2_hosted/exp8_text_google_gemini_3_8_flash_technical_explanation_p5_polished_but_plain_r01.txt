An API rate limit is a restriction set by a service provider on how many requests a client application can make within a specified period of time. For example, a platform might allow one hundred requests per minute from a single user account or IP address. If an application exceeds this threshold, the server temporarily blocks further incoming requests, usually returning an error code indicating that too many requests were sent, and requires the client to wait until the time window resets.

Providers implement these limits primarily to safeguard their infrastructure against overload, ensure fair resource allocation among all users, and protect against automated abuse or denial of service attacks. For software developers, understanding rate limits is essential for building resilient applications that cache data effectively, schedule tasks responsibly, and handle temporary access pauses without crashing.
