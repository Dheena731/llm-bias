A database index is a specialized data structure that improves the speed of data retrieval operations on a table. It works much like the index at the back of a printed book. Without an index, a database must examine every single row in a table from start to finish to find the requested information. With an index, the database maintains an organized, sorted lookup reference that points directly to the exact location of the target data, allowing it to find records almost instantly. While an index dramatically accelerates search queries, it also consumes additional storage space and can slightly slow down data modification tasks, such as inserting, updating, or deleting records, because the index must be refreshed whenever the underlying data changes.
