A database index is a specialized data structure designed to speed up the retrieval of information from a table. It functions much like the index at the back of a physical book. Without an index, finding a specific topic requires scanning every single page from beginning to end, a process known as a full table scan. An index creates an organized, sorted lookup list of specific values paired with pointers to the exact location of the full rows of data. When a search query is run, the database searches this smaller, organized structure to jump directly to the requested records rather than checking every row. While indexes greatly accelerate read performance, they require additional storage space and can slightly slow down write operations because the index must be updated whenever data is added, modified, or deleted.
