A database index is a specialized data structure that speeds up data retrieval from a table. It works by creating a sorted reference that maps column values to the physical locations of the corresponding rows, similar to how an index at the end of a book points you directly to relevant pages. When you run a query, the database consults this index instead of scanning every row, which drastically cuts down search time on large datasets. The trade-off is that indexes consume extra storage space and slow down write operations, because every insert, update, or delete requires the index to be rebuilt or adjusted. For this reason, they are typically added only to columns that are frequently searched, filtered, or used to connect tables.
