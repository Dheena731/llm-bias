A database index is a data structure that significantly speeds up data retrieval operations on a database table. Similar to an index in a textbook, it allows the database engine to locate specific rows without scanning the entire table.

The index creates a sorted copy of one or more columns, storing these values alongside pointers to the physical location of the corresponding data rows. This enables the system to jump directly to the target records rather than performing a full table scan. While indexes accelerate read queries, they require additional storage space and can slow down write operations, as the index must be updated whenever data is inserted, modified, or deleted.
