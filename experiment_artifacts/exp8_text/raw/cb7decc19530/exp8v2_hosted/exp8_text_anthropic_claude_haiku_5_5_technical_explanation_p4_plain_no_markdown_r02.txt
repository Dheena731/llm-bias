Caching speeds up a website by storing copies of data that would otherwise need to be generated or fetched again each time someone visits a page. When a visitor requests a page, the server normally has to run code, query a database, and assemble the content before sending it back. That work takes time. A cache keeps a saved version of the result, so later requests can be answered from the saved copy instead of repeating the work. Caching happens at several levels. A browser can store images, stylesheets, and scripts locally, so returning visitors do not have to download them again. Content delivery networks keep copies of pages and files on servers spread around the world, so a visitor receives the content from a nearby location rather than from a distant origin server. The website's own server may also cache database query results or fully rendered pages in memory. Because the saved copy is ready to send immediately, the page loads faster, the server handles more visitors with less effort, and the network carries less traffic. Good caching depends on setting appropriate expiration times, so that visitors still receive updated content when it changes.
