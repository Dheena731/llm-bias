A database index is a performance optimization tool that allows a database to find specific rows of data much faster than searching through the entire table. It works like the index in the back of a textbook: instead of reading every page to find a topic, you look up the term in the index to get the exact page number. Similarly, a database index creates a sorted copy of column values along with pointers to where that data lives on disk. When a query runs, the database uses this index to jump directly to the relevant data. While indexes dramatically speed up read operations, they do take up extra storage space and can slow down write operations, such as inserting or updating records, because the index must also be updated whenever the underlying data changes.
