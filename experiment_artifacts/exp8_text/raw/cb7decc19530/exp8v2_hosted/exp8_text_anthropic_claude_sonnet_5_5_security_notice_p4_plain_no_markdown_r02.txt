Notice: Please Enable Two-Factor Authentication

To help protect your account from unauthorized access, we strongly encourage all users to turn on two-factor authentication. This feature adds a second step to the sign-in process, so that a stolen or guessed password alone is not enough to get into your account.

When two-factor authentication is active, you will be asked to enter a one-time code in addition to your password each time you sign in from a new device. The code can be generated by an authenticator app on your phone, sent by text message, or provided by a physical security key. An authenticator app or security key is generally safer than text messages, so we recommend one of those options if you have a choice.

Setting it up takes only a few minutes. Open your account settings, find the security section, and select the option to enable two-factor authentication. Follow the on-screen instructions to link your chosen method, then save the backup codes you are given in a safe place. These codes will let you regain access if you lose your phone or security key.

We ask that you complete this step by the end of the month. If you need help at any point, please contact our support team, and we will be glad to guide you through the process.
