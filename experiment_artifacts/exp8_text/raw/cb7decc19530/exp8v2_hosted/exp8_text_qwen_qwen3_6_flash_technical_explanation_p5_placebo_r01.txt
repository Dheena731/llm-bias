An API rate limit is a restriction enforced by an API provider that caps the number of requests a client can make within a defined timeframe. This mechanism protects the service from being overwhelmed, ensures equitable access for all users, and maintains system stability. When a client exceeds the limit, the API typically returns an error response, such as the HTTP 429 Too Many Requests status code, and may include a "Retry-After" value indicating when requests can resume. Limits are commonly measured in requests per minute, hour, or day.
