A database index is a data structure that improves the speed of data retrieval operations on a database table. It functions much like the index at the back of a textbook. Without an index, the database must examine every single row in a table from start to finish to find the matching records. With an index, the database can look up the specific location of the requested data directly, allowing it to retrieve results in a fraction of the time. While an index makes searching and reading data significantly faster, it also consumes additional storage space and can slightly slow down write operations, such as inserting or updating records, because the index must be updated whenever the underlying data changes.
