A database index is a performance optimization tool that allows a database system to find data quickly without scanning the entire table. It works by creating a separate, sorted structure that maps column values to the physical location of the corresponding rows. This is similar to using the index at the back of a textbook to find a topic instantly rather than reading every page. While indexes significantly speed up read operations like searches and filters, they require extra storage space and can slow down write operations because the index must be updated whenever the data changes.
