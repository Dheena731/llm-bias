A database index is a data structure that improves the speed of data retrieval operations on a database table. It functions much like an index found at the back of a physical book. Without an index, the database must examine every single row in a table from start to finish to find the requested information, which can be extremely slow for large amounts of data. With an index, the database keeps a sorted copy of specific columns along with pointers to the original records, allowing it to locate the desired data almost instantly. While indexes make reading and searching data much faster, they require additional storage space and can slow down data insertion, updates, and deletion, because the index must be updated every time the underlying table changes.
