A database index is a data structure that improves the speed of data retrieval operations on a table. Without an index, the database must scan every single row to find the records you are looking for, which becomes slow as the data grows. An index creates a separate, highly organized reference that points directly to the physical location of specific values. When you run a query that filters by an indexed column, the database uses this reference to jump straight to the matching rows instead of reading the entire table. Creating an index requires additional storage space and can slightly slow down write operations like inserts and updates, because the system must update both the main table and the index whenever data changes. Despite these tradeoffs, indexes are essential for keeping read performance fast when working with large amounts of information.
