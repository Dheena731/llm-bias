A database index works like the index at the back of a book. Without an index, the database would have to scan every single row in a table from top to bottom to find specific information, which is slow and inefficient. An index creates a sorted reference structure that points directly to the location of the data, drastically speeding up search and retrieval queries. The main trade-off is that indexes require additional storage space and can slightly slow down adding or updating data, since the index itself must be updated whenever changes occur.
