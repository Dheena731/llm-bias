All employees are reminded that using the same password for multiple accounts, both personal and work-related, poses a significant security risk to our organization. If one of your personal accounts is compromised, the same password could be used to gain unauthorized access to our systems, potentially leading to data breaches and other security incidents.

To protect our workplace and sensitive information, it is essential that you use unique and complex passwords for all work-related accounts. You should also avoid using the same password for any personal accounts that may contain sensitive information.

If you are currently using the same password for multiple accounts, please take immediate action to change your passwords and ensure that each account has a unique and secure password. If you need assistance with password management or have concerns about workplace security, please contact our IT department for guidance and support.
