A database index is a tool that speeds up searching for data within a table by creating a specialized structure that allows the system to find rows quickly without examining every single record. You can think of it like the index at the end of a textbook; instead of flipping through every page to find where a term appears, you look up the term in the index and go directly to the relevant pages. Similarly, a database index maintains a sorted list of values from one or more columns along with pointers to their locations in the table. When you run a query with a filter on an indexed column, the database uses this structure to jump straight to the matching data, making the operation much faster than a full table scan. This performance gain comes with trade-offs, as indexes require additional storage space and slow down write operations like inserts and updates because the index must be kept synchronized with the table data.
