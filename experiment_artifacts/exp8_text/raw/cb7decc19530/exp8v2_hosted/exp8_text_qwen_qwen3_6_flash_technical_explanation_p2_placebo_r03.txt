A database index is a supporting data structure that accelerates data retrieval by allowing the database to locate specific rows without scanning the entire table. When a query runs without an index, the database performs a full table scan, checking each row sequentially until it finds matches. An index creates a pre-sorted reference that maps column values directly to their physical locations, enabling the engine to jump straight to the relevant records. This dramatically reduces read latency for frequently searched or joined columns. The trade-off is that indexes consume additional storage space and slow down write operations, because every insert, update, or delete must also modify the index to stay synchronized. Indexes are therefore used to optimize read performance while accepting measurable overhead on data modifications.
