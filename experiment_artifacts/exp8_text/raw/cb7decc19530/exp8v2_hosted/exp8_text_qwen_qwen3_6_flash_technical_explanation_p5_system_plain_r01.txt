An API rate limit is a restriction placed on how many requests a user or application can send to a server within a specific period of time. This control mechanism prevents any single client from consuming excessive resources, which helps maintain server stability, ensures fair access for all users, and protects the system from malicious attacks or poorly coded software that might flood the endpoint with calls. When a client exceeds the permitted threshold, the server typically returns an error response and pauses accepting further requests until the time window resets. These limits are commonly measured in requests per minute or hour, and they are often communicated through response headers so developers can monitor usage and adjust their applications to stay within the allowed boundaries.
