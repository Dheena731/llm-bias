An **API rate limit** is a rule set by an API provider that restricts how many requests a client can make within a given time window (e.g., 100 requests per hour). It's used to prevent abuse, ensure fair access for all users, and protect the provider's servers from overload or downtime. When you hit the limit, further requests are blocked until the window resets, usually returning an HTTP `429 Too Many Requests` error. To stay compliant, developers implement strategies like caching responses, batching requests, or adding exponential backoff retries.
