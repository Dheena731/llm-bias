An API rate limit is a restriction set by a web service that controls how many requests a user or application can send within a specific timeframe. For example, an API might allow a maximum of 100 requests per minute. 

Platforms use rate limits to prevent server overload, stop malicious abuse, and ensure fair performance for everyone. If an application exceeds this limit, the server will temporarily reject further requests, usually returning an error code indicating that too many requests were made, until the time window resets.
