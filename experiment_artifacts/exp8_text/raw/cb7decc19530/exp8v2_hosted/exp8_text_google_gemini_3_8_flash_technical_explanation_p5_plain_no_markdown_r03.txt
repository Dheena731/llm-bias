An API rate limit is a restriction imposed by a service provider on how many requests a user or application can send to an API within a specific period. For instance, a system might allow only sixty requests per minute from a single account. Service owners use these limits to keep their servers from crashing due to sudden spikes in traffic, to protect against malicious attacks, and to ensure that computing resources remain available for everyone. When an application sends more requests than the permitted limit, the server temporarily blocks additional incoming traffic and returns an error response, requiring the user to wait until the time window resets before trying again.
