A database index is a data structure that speeds up the retrieval of rows from a table. Without an index, the database must scan every row to find those that match a query, which becomes slow as the table grows. An index stores a sorted or organized copy of one or more columns, along with pointers to the corresponding rows, so the database can locate matching data quickly, much like a book's index helps a reader find a topic without reading every page. The tradeoff is that indexes consume additional storage and must be updated whenever rows are inserted, updated, or deleted, which can slow down write operations. For this reason, indexes are typically created on columns that are frequently used in search conditions, joins, or sorting.
