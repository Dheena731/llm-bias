A database index is a supplementary data structure that accelerates data retrieval by allowing the database engine to locate specific rows without scanning the entire table. When you run a query, the index provides a direct mapping from search values to their physical locations on disk, reducing lookup time from linear to near-constant for indexed columns. This performance gain comes with a trade-off: indexes consume additional storage space and require maintenance during insert, update, and delete operations, which can slow write performance. In short, an index optimizes read speed at the expense of extra storage and slightly reduced write efficiency.
