When a person visits a website, their browser typically has to request information, such as images, code, and text, from a distant web server. The server must locate or generate that data and send it back over the internet, which takes time. Caching speeds up this process by saving copies of those files in temporary storage locations that are closer to the user, such as inside the user's web browser or on nearby intermediate servers. When the visitor returns to the site or loads a new page that uses the same elements, the browser retrieves the saved files directly from the cache rather than requesting them from the original server again. Because reading data from a local or nearby cache takes a fraction of the time required to download it from a remote machine, the website loads much faster and the main server experiences less strain.
