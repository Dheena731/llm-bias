A database index is a data structure that speeds up the retrieval of rows from a table. Much like the index at the back of a book, it lets the database find matching records without scanning every row. The index stores the values of one or more columns in a sorted or hashed form, along with pointers to where the corresponding rows live on disk. When a query filters or sorts on an indexed column, the database can jump directly to the relevant entries instead of reading the entire table. The tradeoff is that indexes consume extra storage and add overhead to inserts, updates, and deletes, since the index must be kept in sync with the data.
