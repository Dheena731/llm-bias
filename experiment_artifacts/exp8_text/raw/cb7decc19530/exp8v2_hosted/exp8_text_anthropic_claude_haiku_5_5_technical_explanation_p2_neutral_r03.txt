A database index is a data structure that speeds up the retrieval of rows from a table. Much like the index at the back of a book, it lets the database find matching records without scanning every row. The index stores the values of one or more columns in a sorted or hashed form, along with pointers to the locations of the corresponding rows. When a query filters or sorts on an indexed column, the database can use the index to jump directly to the relevant data instead of reading the entire table.

The tradeoff is that indexes consume extra storage and must be updated whenever rows are inserted, updated, or deleted, which can slow down write operations. For this reason, indexes are typically created on columns frequently used in search conditions, joins, or ordering.
