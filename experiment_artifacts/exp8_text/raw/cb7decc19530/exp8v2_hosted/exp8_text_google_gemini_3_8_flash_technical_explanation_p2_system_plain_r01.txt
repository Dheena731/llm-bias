A database index is a specialized data structure that improves the speed of data retrieval operations on a database table. It functions much like the index at the back of a textbook. Instead of reading every single page to find a specific topic, you can look it up in the index, which points directly to the correct page. Without an index, a database engine must perform a full scan, examining every row in a table from start to finish to find matching records. By creating an index on certain columns, the database keeps a sorted, compact reference of those values along with direct pointers to the actual data rows. This allows the system to find the requested information in a fraction of the time. While an index dramatically speeds up search queries, it also requires additional storage space and can slightly slow down data insertion, updates, and deletion, because the index must be updated whenever the underlying data changes.
