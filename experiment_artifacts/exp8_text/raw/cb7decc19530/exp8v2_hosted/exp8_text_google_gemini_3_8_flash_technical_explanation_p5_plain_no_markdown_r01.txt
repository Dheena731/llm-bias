An API rate limit is a restriction imposed by a service provider that controls how many requests a user or application can make within a specific period. For example, a service might allow one hundred requests per minute. If an application exceeds that threshold, the server temporarily blocks additional requests until the time window resets, usually returning an error message. Providers use rate limits to protect their infrastructure from being overloaded by excessive traffic, prevent malicious abuse, and ensure that resources remain fairly distributed and accessible to all users.
