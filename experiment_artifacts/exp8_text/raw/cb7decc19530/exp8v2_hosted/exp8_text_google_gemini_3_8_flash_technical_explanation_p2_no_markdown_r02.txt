A database index works like the index at the back of a book. Instead of searching through every single row in a table to find specific information, the database uses the index to jump directly to the exact location of the data.

Technically, an index is a separate data structure that stores a sorted copy of specific columns along with pointers to the original rows. While this drastically speeds up search and retrieval operations, it comes with a trade-off: indexes consume extra storage space and can slightly slow down adding or updating data, since the index must be updated whenever the table changes.
