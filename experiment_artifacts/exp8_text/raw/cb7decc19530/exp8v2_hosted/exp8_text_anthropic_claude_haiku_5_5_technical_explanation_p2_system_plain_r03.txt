A database index is a separate data structure that helps the database find rows quickly without scanning the entire table. It works much like the index at the back of a book: instead of reading every page to locate a topic, you consult a sorted list that points you to the exact pages where it appears. In a database, an index is typically built on one or more columns, and it stores the values from those columns in an organized form, often a B-tree, along with pointers to the matching rows. When a query filters or sorts on an indexed column, the database can use the index to jump directly to the relevant rows, which can dramatically speed up reads. The tradeoff is that indexes take up additional storage and must be updated whenever rows are inserted, modified, or deleted, so writes can become slightly slower. For this reason, indexes are usually created on columns that are frequently searched, joined, or used for ordering.
