A database index is a supporting data structure that significantly speeds up data retrieval. When you run a query, the database normally has to examine every row in a table until it finds the matches, which becomes slow as data grows. An index solves this by maintaining a separate, organized map that links specific column values directly to the physical location of their corresponding rows. This allows the database to jump straight to the relevant data instead of scanning the entire table. The trade-off is that indexes consume additional storage space and slightly slow down write operations, because every insert, update, or delete must also maintain the index structure.
