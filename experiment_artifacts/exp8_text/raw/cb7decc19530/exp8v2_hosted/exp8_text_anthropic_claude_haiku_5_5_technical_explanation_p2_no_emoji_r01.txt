A database index is a data structure that speeds up the retrieval of rows from a table. Without an index, a query often has to scan every row in a table to find matches, which becomes slow as the table grows. An index stores a sorted or organized copy of one or more columns, along with pointers to the corresponding rows, so the database can locate matching records quickly, much like a book's index helps a reader find a topic without reading every page. The tradeoff is that indexes take additional storage and must be updated whenever rows are inserted, updated, or deleted, which can slow down write operations.
