Caching speeds up a website by storing copies of data or files so they can be delivered quickly without being rebuilt or fetched again from the original source each time someone asks for them. Many pages contain elements that rarely change, such as logos, stylesheets, scripts, and images. Without caching, a visitor's browser must request each of these from the server every time, and the server must work to generate or retrieve them. When caching is in place, the browser can keep a local copy of these files and reuse them on later visits, which avoids repeated network trips and reduces load on the server. Servers and intermediary systems, such as content delivery networks, can also keep copies of entire pages or database query results close to users. When a request arrives, the cached copy can be sent immediately instead of running the full process to produce it again. The result is faster page loads, lower bandwidth use, and a site that can handle more visitors at once with the same hardware.
