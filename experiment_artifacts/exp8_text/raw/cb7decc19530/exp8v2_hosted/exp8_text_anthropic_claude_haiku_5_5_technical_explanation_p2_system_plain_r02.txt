A database index is a separate data structure that helps the database find rows quickly without scanning an entire table. It works much like the index at the back of a book: instead of reading every page to locate a topic, you consult the index, which lists where each item appears. In a database, an index is typically built on one or more columns, and it stores those column values in a sorted or tree-like form (often a B-tree), along with pointers to the matching rows. When a query filters or sorts on an indexed column, the database can jump directly to the relevant entries, which greatly speeds up reads. The tradeoff is that indexes take up additional storage and must be updated whenever rows are inserted, changed, or deleted, so writes can become slightly slower. Good indexing therefore means balancing faster lookups against the cost of maintaining them.
