Filters the dataset to include only records that meet the criteria you select. Choose one or more values to narrow the results, and the table, charts, and summary statistics will update to reflect the filtered set. Selecting multiple values within a single filter returns records that match any of them, while combining filters returns only records that satisfy all of them. Records with missing values for the filtered field are excluded unless you choose to include them. Clearing the filter restores the full dataset, and exported files will contain only the filtered records.
