An API rate limit is a restriction set by a service provider that controls how many requests a user or software application can make to a server within a specific period. For instance, a provider might limit users to one hundred requests per minute. Once this threshold is reached, the server will temporarily block or reject further requests until the timer resets. Rate limits are primarily used to prevent system overloads, protect servers from malicious abuse, ensure fair performance for all users, and manage operating costs.
