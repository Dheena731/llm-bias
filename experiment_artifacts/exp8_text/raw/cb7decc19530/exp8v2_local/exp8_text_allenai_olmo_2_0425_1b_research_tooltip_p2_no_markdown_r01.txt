In other words, the confidence intervals are too narrow, and they contain the true value. I need a confidence interval where the lower and upper bounds don't contain the true value at all!

Is there any way to have confidence intervals that are a little wider, but still represent the true value?


No, there isn't. Confidence intervals are always a little wider than confidence levels. That's because the confidence level is a confidence interval.

To get narrower ones, you would have to have a better model. To use a logistic regression to get narrower confidence intervals, you have to include more and more explanatory variables. It's not a practical approach, and you'd be better off just using better or a different model.
