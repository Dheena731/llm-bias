It is a rate limit set by the company who's API is being used. DigitalOcean does not have an API rate limit, but companies like AWS and Google do.

If you're using DigitalOcean's API, you will need to call your API endpoint while you're waiting for the rate limit to expire. This is a very common technique among developers.

If you don't want to wait for the rate limit to expire, you'll have to try to create a bad request. This is done by adding a random character to the end of any request you make to the API endpoint.
