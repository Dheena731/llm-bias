Asking the right question

It’s not always obvious when to ask an AI question, or how to ask it, but

wrong questions stifle growth and understanding.

  • Do not ask a question that can be answered in one word or phrase.
  • Do not ask a question that can be answered by a single search term.
  • Do not ask a question that can be answered by an existing AI algorithm.
  • Do not ask a question that can be answered by looking up the answer on Wikipedia.
  • Do not ask a question that can be answered by looking up the answer on a search engine.
  • Do not ask a question that can be answered by looking up the answer on the Internet.
  • Do not ask a question that can be answered by simply Googling the question.
  • Do not ask a question that is too specific.
  • Do not ask a question that is too vague.
  • Do not ask a question that does not resonate with the users of your site.
  • Do not ask a question that can be answered by an existing AI algorithm.

Asking the right question

A good question will be able to tell us why, how and who. 

Example: Which 3D printer prints in color?

3d printer color? 

  • Why: 3D printers can print in color.
  • How: 3D printers heat up a plastic material with a nozzle.
  • Who: 3D printers are used by home and commercial cake decorators.

Looking for the right question can be difficult. 

It becomes even more complicated if you have an existing AI algorithm that can answer your question. The algorithm should be able to differentiate between valid and invalid questions. It should be able to tell when someone is manipulating the system to obtain an answer and should be able to prevent that from happening.

How does an AI machine learn?

An AI machine learns by experience. Experience is gained by having the machine interact with the environment it finds itself in. The environment is made up of other AI machines and humans. 

The way the AI machine interacts with the environment is by performing actions. Actions are done by the AI machine by seeing an input and deciding what action to take to solve that input. 

AI machines learn by doing actions and every action has an output. An output is the reference made by the AI machine to an input. 

Let us look at the examples mentioned in the previous section in terms of how the AI machine learns.

Example 1
"Aurora is a 3D printer that can create objects out of plastic material." 

An AI machine will read this phrase and learn that it can create something. Then it can be asked a question such as, "How can Aurora create something?"

Example 2
"Aurora is a 3D printer that can create something, and it does so using a plastic material." 

This new information tells the AI machine that it uses the plastic material to create something.
