All web applications should be designed as flexible and extensible. This is a key principle in the 'web application' part of the 'web' domain.

If a user doesn't like the implementation, the user should be able to change it. The same applies to design - it should be flexible and extensible. This is a core tenet of modern accessibility design.

If a user cannot change the solution (or the design doesn't allow them to change it) then it isn't an acceptable solution.
