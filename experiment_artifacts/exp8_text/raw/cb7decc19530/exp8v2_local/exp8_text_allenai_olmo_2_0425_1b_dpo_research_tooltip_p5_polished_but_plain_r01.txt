To customize the export options for query results, simply right-click on the desired cell or the grouped analysis and select 'Export Results'. This option will open a dialogue where you can specify the file format and location. Choose a `.csv`, `.xlsx`, `.pdf`, or any other file type you prefer. Enter the desired filename and space for the file location, then click 'Save'. Your query results will be saved to the specified location in a format compatible with the chosen file type, allowing you to share or retrieve them as needed.
