(Please use a language-neutral, formal, and concise language, e.g., don't use contractions such as "y'day".)


Be mindful that users expect tooltips to be short and to carry the same information as the label, so you should not make the tooltip longer than the label. Use a language-neutral, formal, and concise language.

Information Density

If you want to use a "strange-lookin' date" for the tooltip to emphasize a particular date, your users might not know what the date is. If you want to emphasize a "strange-lookin' date", choose a date that the users are familiar with, like a Monday or a Friday, so it can be associated with the correct date. You can customize the visual style of the date using CSS.

Visual Style

The tooltip text is styled with a custom color, font color, line-height, and background color. You can customize the visual style of the date with CSS. See the theme for an example.

Date Range

Add a space after the start of the date, then a caret C at the end of the date. An event starts at that point, and ends when the caret moves to the next hand-shaped character. For example, the following string is appended to the end of a string: "2014-12-25 01:12:13". Note that you can change the string to something else, if you want to add your own text to the end of the date.


A date range selector may be a single element or an array of elements. Write a tooltip for each element of the range.
