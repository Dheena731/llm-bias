Use the CSS classes specified in the API documentation to style your tooltip: tooltip, tooltip, tooltip-default.

The tooltip() function returns the HTML of the tooltip, which you should generate in memory and then save to the data table. You can use the unlink() function to store the tooltip to the data table.

The API documentation also describes the attributes of the tooltip Element.

You can use the following code to create a simple table and select data from it:

document.querySelector('.col').addEventListener('click', function() {
  const table = this.parentNode.querySelector('table');
  const tr = table.querySelector('tr');
  const td = table.querySelector('td');

  const first = new Date();
  const second = new Date(new Date().getTime() + 5 * 1000);
  const third = new Date(new Date().getTime() + 5 * 1000 + 1000);
  const fourth = new Date(new Date().getTime() + 5 * 1000 + 1000 + 1000);

  tr.addEventListener('click', function() {
    td.innerHTML = first.toLocaleString() + ' ago';
    td.innerHTML = second.toLocaleString() + ' ago';
    td.innerHTML = third.toLocaleString() + ' ago';
    td.innerHTML = fourth.toLocaleString() + ' ago';
  });

  table.appendChild(tr);
  table.appendChild(td);
});
