What are the advanced guidelines?

Here are some tips to make your explanations more engaging. This is not a hard-and-fast rule, but we hope these tips help you write clearer and more memorable explanations.


Your goal should be to guide the reader through the topic, not just list facts. Describe how the concept works

"Data storage is broken" isn't an explanation. "Data storage is broken because the hardware is unable to completely randomize the contents of a magnetic disk, causing data to be lost at random" is much better.

Avoid glossing over important concepts

Don't be afraid to use technical terms if they're important to the explanation. For example, if you're explaining how to use a voting machine and don't know the term "ballot box", you should probably use it.

Describing a concept with a more common term is a good way to avoid using a technical term, too. For example, the term "ballot box" is much easier to understand than "ballote box".

Be sensitive to content discrimination issues

"Is your virus safe?" is a great title for an explanation. "Is your virus safe?" is a terrible title for an explanation. You have a duty to write content that is both accurate and understandable.

If you don't know the term, don't use a technical term. Use a more common word to avoid "content discrimination."

Use long paragraphs

When writing an explanation, put the main point of the paragraph near the beginning. You should always put a short introductory sentence at the beginning of a paragraph. The rest of the paragraph should describe the main point more completely.

Start off with a paragraph of 1-5 sentences. 1-5 sentences is a good length for a simple explanation. 7-10 sentences is a good length for a more complex explanation.

Examples and explanations using images and video

In most cases, it's best to write an explanation that uses text and images in addition to text. Using images and video is great, but it adds a lot of overhead. You should only use them if it's necessary and benefits the explanation.

For example, a video of a computer sneezing is good because it shows what's happening on the computer in a way that text can't. But explaining the function of the "Swap File" is easier if you just write it out.

Use the words "and" and "or"

When writing an explanation, it's helpful to use "and" and "or" to indicate how the concept works. For example, "AND The and Server can be written slightly differently to avoid any ambiguity." is better than "The server can be written slightly differently to avoid any ambiguity."

Make sure your explanation tells a story

An explanation should be a narrative with an introduction, a body, and an ending. It should include all the important information and shouldn't leave anything out. That means you have to include the topic, the proper order of steps, the remaining vocabulary, and the conclusion.

Don't be afraid to tell a story

Remember, an explanation is like a movie. It's made of clips that you need to put together. So it's fine to write in a narrative style. In fact, if you're writing an explanation, you should probably write it in a narrative style!

Use Inclusive Language

When writing an explanation, it's important to use inclusive language. This means saying "people" instead of "people of color", "she" instead of "he", or "he or she" instead of "he or she or they".
