## 12.3.4. Two-Column Layouts

One of the most popular layouts in the WordPress theme repository is the two-column layout.

The two-column layout is shown in the screenshot below. The two-column layout can be used by including the custom-columns class in the header and footer:

/** @file */
/**
 * @package WordPress
 * @subpackage Twenty_Ten
 */
/** @var WP_Customize_Manager */
$wp_customize->add_section('twenty_ten_default_section',
    array(
        'name' => 'twenty_ten_default',
        'priority' => 200,
        'description' => 'Front matter for the default (Ben Twelves) Twenty Ten Theme',
        'section' => 'twenty_ten_header',
        'settings' => array(
            'template' => 'twenty_ten_header_template'
        ),
        'content' => array(
            array(
                'label' => 'Front matter',
                'type' => 'inline',
                'priority' => 100,
                'weight' => 100,
                'description' => 'Set the front matter content.',
                'section' => 'twenty_ten_header_content',
            ),
            array(
                'label' => 'Header',
                'type' => 'text',
                'priority' => 101,
                'weight' => 101,
                'description' => 'Set the header content.',
                'section' => 'twenty_ten_header_content_section',
            ),
            array(
                'label' => 'Footer',
                'type' => 'text',
                'priority' => 100,
                'weight' => 100,
                'description' => 'Set the footer content.',
                'section' => 'twenty_ten_header_content_section',
            ),
            'source' => 'twenty_ten_header_template'
        )
    )
);
