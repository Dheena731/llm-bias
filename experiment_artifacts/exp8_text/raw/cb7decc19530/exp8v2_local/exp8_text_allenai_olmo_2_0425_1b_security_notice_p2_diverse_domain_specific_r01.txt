What is an email phishing?

Phishing is the practice of using email as a method of collecting personal information from unsuspecting recipients, including account log-in credentials. This information can then be used for cybercrime such as identity theft, financial fraud, and ransomware.

The RFC 5322 email standard defines how email messages are structured, including the email header and the body of the message itself.

For example, the body of an email message might look like this:

X-Test: This is an example of a test message.

The email header might look like this:

From: Mark Smith <> (marksmith)
To: Scott Jones <>
Subject: This is a test message

The first line of an email message shows the sender’s address, and the second line shows the subject line.

There is also a header in the body of an email message called “CRL” (Critical-Revocation List). This header contains information about the signatures of the mail-handling software used to process the message. It is used to control what should be done with the message.

If an email message has been modified in some way, it might contain another header called “DKIM”.

This header is used to identify which mail-handling software was used to process the message.
