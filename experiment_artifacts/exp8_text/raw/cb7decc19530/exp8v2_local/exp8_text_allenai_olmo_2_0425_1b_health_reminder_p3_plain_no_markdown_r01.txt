8.4.8 Use a monospaced font.

Create a template and make it a default so that every time you create a new text document, it'll use this template.

To create a default document template, go to Settings → General → My Templates → Create new template → Monospaced font.

This will create a template named template. You can modify the template however you want (for example by changing the fonts, colors, and styles). Once it is ready, you can select it and use it as a default template for new documents.

8.4.9 Create a monospaced font.

You can create a monospaced font of your own (for example, for a particular project or use) by simply copying a normal font, choosing it as a monospaced font, and then setting it as a default.

8.4.10 Use a monospaced font for definition lists.

A definition list is a list of items, of which each item is a simple term. A definition list is usually used to list the definitions of terms in a document. The items themselves can be normal prose or they can be defined terms.

This is the way a definition list that uses non-standard terms looks like
