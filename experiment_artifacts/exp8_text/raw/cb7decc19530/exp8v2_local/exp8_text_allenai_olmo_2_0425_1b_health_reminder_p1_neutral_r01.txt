table structure

As you can see, the table is a stacked bar chart. In a basic bar chart, the data is displayed as separate bars all stacked on top of each other.

In the case of a stacked bar chart, the labels are placed below and parallel to the axis. The data is still calculated based on the total values in the range.

The difference between stacked and regular bar charts is that in a regular bar chart, the values are shown as separate bars with the bar height representing the value.

In a stacked bar chart, the bars are still connected to the axis, but the value is represented by the height of the bar. This allows us to show a greater range of values on a single graph.
