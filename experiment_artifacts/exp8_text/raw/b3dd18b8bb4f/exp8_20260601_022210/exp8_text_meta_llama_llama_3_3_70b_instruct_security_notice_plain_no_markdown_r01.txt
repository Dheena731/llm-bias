As part of our ongoing efforts to maintain a secure work environment, we would like to remind all employees of the importance of using unique and complex passwords for all work-related accounts. Reusing passwords across multiple sites and systems poses a significant security risk, as a breach of one system can potentially compromise all others that use the same password. To minimize this risk, please use a different password for each work-related account and avoid using the same password for both work and personal accounts. If you have any questions or concerns about password security, please contact the IT department for assistance.
