All employees are reminded that using the same password for multiple accounts, including personal and work-related accounts, poses a significant security risk. If one account is compromised, all accounts with the same password will also be at risk. To protect company data and systems, it is essential that you use unique and complex passwords for your work accounts. If you are currently using the same password for multiple accounts, please change your passwords to unique and complex ones as soon as possible. Remember that password security is everyone's responsibility and plays a critical role in protecting the company's assets and information. If you have any questions or concerns about password security, please contact the IT department for assistance.
