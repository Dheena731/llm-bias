To all employees,

As a reminder, please be aware that reusing passwords across multiple accounts is a security risk. Using the same password for both personal and work accounts makes it easier for unauthorized individuals to gain access to sensitive information.

To minimize this risk, we recommend using unique and complex passwords for all accounts, including work email, network login, and any other system or application you access through our network.

If you have reused passwords in the past, please take the time to update them as soon as possible. If you need assistance or have any questions about password management, please reach out to the IT department.

Thank you for your cooperation in maintaining the security of our network and sensitive information.
